- 「크롬 연결되어있는데 왜 안돼 가짜 db 돌리고서 크롬 클릭하면되잖아」
- 「학생용 학부모용도 모두 해봐. 그리고 학부모, 학생에서 클릭했을때 그게
   원장에 제대로 뜨는지까지, 원장에서 넣었을때 학생 학부모에게 뜨는지 확인」

## 쓰는 법

    bash scripts/e2e/run.sh

몇 분 걸립니다. 평소 검사(`scripts/check-pages.sh`)와 따로 둔 이유가
그것입니다 — 그쪽은 몇 초면 끝나야 자꾸 돌리게 됩니다.

## 무엇으로 세우나

`supabase start` 는 도커 이미지를 받아옵니다. 이 환경은 **컨테이너 이미지
내려받기가 막혀 있어서**(레지스트리 셋 다 403) 조각을 직접 세웁니다.

| 조각 | 여기서는 |
|---|---|
| Postgres | 이미 깔려 있는 것 (SQL 검사가 쓰던 것) |
| 표를 HTTP 로 (PostgREST) | 내려받아 그대로 씁니다 — 진짜 Supabase 도 이걸 씁니다 |
| 로그인 | `auth.mjs` 가 흉내 냅니다 |
| 사진 보관함 | **없습니다** |

**앱 코드에는 손대지 않습니다.** 테스트를 위한 구멍을 앱에 내면 그 구멍이
실수로 켜진 채 배포되는 날이 옵니다. 앱은 자기가 진짜 Supabase 에 붙는 줄
알고 그대로 돕니다 — 그래야 검사한 것이 실제로 도는 것과 같습니다.

읽기 규칙(RLS)은 **진짜 그대로** 돕니다. PostgREST 가 JWT 를 풀어
`auth.uid()` 에 넣어주는 자리가 진짜와 같아서, 규칙을 하나도 안 고쳤습니다.

## 무엇을 보나

1. 들어가면 자기 자리로 (원장→대시보드 · 학생→학생 · 학부모→학부모)
2. 원장이 여는 화면 25개가 다 열리고, 비어 있지 않고, 오류가 없나
3. 눌렀을 때 화면이 실제로 달라지나
4. 학생에게 남의 화면이 안 열리나
5. 학생·학부모 화면이 비어 있지 않나
6. **오간 것이 서로에게 닿나**
   - 어머니가 전달 → 원장 대시보드에 뜨나
   - 원장이 전달사항 → 학생 화면에 뜨나

## 못 보는 것

- **사진** (보관함이 이 판에 없습니다)
- **앱 알림** (VAPID · 진짜 브라우저 권한이 필요합니다)
- **문자 발송** (솔라피)

안 본 것을 봤다고 하면 검사가 없는 것보다 나쁘므로, 검사 끝에도 이걸
적어둡니다.
