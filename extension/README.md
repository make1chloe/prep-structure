# 🃏 클래스카드 확장 — 까는 법 (원장님용)

크롬에서 **한 번만** 하시면 됩니다. 그 뒤로는 크롬이 켜져 있는 동안 15분마다 저절로 보냅니다.

1. 앱에서 **설정 › 🔌 연동 열쇠 › 🃏 클래스카드 확장** 의 「확장 열쇠」를 정하고 저장합니다
   (아무 긴 글자나 되고, 남에게 안 알려 주시면 됩니다 — 20자 넘게 권합니다).
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드** → 이 `extension` 폴더를 고릅니다.
4. 크롬 오른쪽 위 🧩 에서 「클로이영어 — 클래스카드」를 눌러 **앱 주소**와 **확장 열쇠**를 넣고 **저장**.
5. **지금 보내기** 를 눌러 보십니다. 아래 상자에 「보냈습니다 — 아이 N명 · 읽은 줄 N」 이 뜨면 된 것입니다.

## 잘 안 될 때

| 뜨는 말 | 뜻 · 하실 것 |
|---|---|
| 클래스카드 로그인이 풀렸습니다 | 크롬에서 클래스카드에 다시 로그인하시면 됩니다 |
| 열쇠가 다릅니다 | 앱 설정 🔌 의 🃏 줄과 팝업의 열쇠가 다릅니다 — 다시 옮겨 붙여 주세요 |
| 안 이은 아이디 N | 그 아이를 앱 **학생** 화면에서 클래스카드 아이디에 이어 주시면 다음부터 들어갑니다 |
| 학생 명단을 못 읽었습니다 | 클래스카드 화면이 바뀐 것입니다 — 저에게 말씀해 주세요 |

## 안 하는 것

- **비밀번호를 묻지도, 저장하지도 않습니다.** 크롬에 이미 로그인된 클래스카드 세션을 그대로 씁니다.
- **잘했나 못했나를 확장이 정하지 않습니다.** 긁은 것을 그대로 앱에 보내고,
  「목표 대 실제」도 3초훈련을 빼는 것도 앱이 합니다(확정-⑩·⑱).
  그래서 규칙이 바뀌어도 **확장을 다시 깔지 않으셔도 됩니다.**
- **목표에 못 미쳐도 앱이 알아서 넘기지 않습니다** — 원장님이 보시고 누르십니다.

## 안에서 도는 것 (제 메모)

`background.js` 가 15분마다 ① 명단(`/Pro/ReportAllPlanner`) ② 오늘·내일 세트
(`/Pro/getPlannerLearnStatus`) 를 읽어 `POST <앱>/api/cc` 로 보냅니다.
열쇠는 `Authorization: Bearer` 머리글에만 싣습니다(주소·자취에 안 남습니다).
앱 상한(아이 200 · 줄 600)에 맞춰 짐을 나눠 보냅니다 — 넘겨 보내면 앱이 짐 전체를 되돌립니다.
지킴: `node scripts/check-ext.mjs` (14건).
