# 업무루틴 — 주별

> [[업무루틴-지도]] · 지키는 규칙: [[업무루틴-규칙]] §출결·보강 · 위 층위: [[업무루틴-월별]] · 아래 층위: [[업무루틴-일별]]

## 1. 한 주의 요일 구조

| 요일 | 무엇 |
|---|---|
| 월 ~ 목 | **정규수업** (월·수 / 화·목 짝 — 반별 요일·시간은 `classes` 에만 있다) |
| 금 | **보강·특강 전용** — 정규 회차에서 뺀다 (설정 → 보강만 하는 요일, 지금 값이 금) |
| 토·일 | 원칙적으로 없음. **시험이 월요일이면** 토·일 보강 (앱은 보강 날짜를 수업일로 안 막는다) |

금요일 규칙은 [[2026-회차점검]]에서 확정된 것이다 — 노션 시절 「설명 안 되는
결측 7일」 이 전부 이것이었고, 회차·수강료가 이 규칙 위에서 돈다.

## 2. 주 단위로 도는 신호 (대시보드가 띄운다)

| 신호 | 창 | 하는 일 |
|---|---|---|
| 결석 예정 | 오늘~7일 | 미리 연락받은 결석 — 그날 기다릴 필요 없는 학생으로 접힌다 |
| **보강 필요** (개명 8/21) | **기간 제한 없음 — 결정할 때까지 무조건 누적** (하한은 출결 관리 시작 2026-08, 앞은 30일) | 출처(시험기간 일괄 · 학부모 요청 · 이관)와 함께. 잡거나 `보강 없음` 처리해야만 내려간다. 셈·창 모두 한 벌(buildMakeupRows) |
| 시험 임박 | D-21부터 | 범위 미등록이면 같이 재촉 ([[업무루틴-학기별]]) |
| 전날 등원 | 영어 시험일 전날 | 학교 시험만 — 모의고사는 안 부른다 |
| 이번 주 생일 | 7일 | 월·일 적힌 학생만 |
| 클카 플래너 소진 | 마지막 마감 3일 내 | 플래너 새로 잡기 (단어 교재 끝나감과 나란히) |
| 되풀이 할일 (매주) | 지정 요일 | `todo_routines` weekly — 요일마다 저절로 생긴다 |

## 3. 주간 리듬을 만드는 학생 쪽 루틴

- 숙제는 **수업일 단위**로 도니까 (다음 수업까지), 주 2회 반이면 학생의 한
  주는 「수업 → 숙제 → 수업 → 숙제」 두 박자다. 예습(다음 단원)·복습(오늘
  단원)의 구분은 루틴이 안다 ([[업무루틴-수업별]]).
- 주말 배정이 정해진 교재도 있다 (예: 3300제 — 주말 4페이지, 문법 4가지
  1페이지씩. [[기본학습-정리-2026-08-14]]).
- **단어 재시험은 그날 남아서 다시 본다** (하원 안내의 늦귀가 사유로 자동으로
  잡힌다) — 오늘 명단은 `op=retest`(오늘 90% 미만). 날짜를 따로 잡는
  재시험·보강에는 기본으로 **다음 보강 요일**(설정, 기본 금)이 채워진다.

## 4. 주간에 몰아 하는 확인

- **숙제 미흡·미제출이 잦은 아이** — 최근 2주 3건 이상이면 대시보드
  watchList 에 오른다. 주중 상담·전화의 재료.
- **등원 밀림** — 최근 수업에서 「다음 수업에 계속」 이 2개 이상이면 눈덩이
  신호 (원장님: 「나보다 학생한테도 떠야 할 듯」 — 학생 배너도 있다).
- (개발 쪽 주의) 원장님 활동 시간대엔 **배포를 몰아서(한 번에)** 한다 —
  배포 교체 순간마다 폰 앱이 죽는 이슈라 교체 횟수를 줄인다
  ([[2026-08-21-핸드오프]]).
