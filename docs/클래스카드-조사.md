# 클래스카드 조사 — 2026-08-12~13 (직접 조작)

원장님 계정(make1chloe, Max 요금제)으로 로컬 크롬에서 직접 열어 확인했다.
핸드오프 §7-1의 「모르는 것」이 모두 풀렸다.
앱 저장소를 클론하면 이 문서를 `docs/`로 옮길 것.

## 0. 계정 구조 — 원장님이 실제로 쓰고 계신 방식

- 클래스 378개. 왼쪽 카테고리(교과서 · 단어 · 독해 · 듣기 · 모의고사 · 문법 ·
  문법훈련 · 보관 · 블록구문 · 수행평가 · 어휘 · 영작 · 의미덩어리 · 특강 ·
  학교자료)를 펼치면 **학생 이름별 / 교재별 클래스**가 나온다.
  예: 수행평가 → 공시연 · 구도은 · 김서은 · 박주영 · 서한결 · 윤서영 · 정현수 · 홍채은.
- 즉 원장님의 실사용 구조는 **영역(카테고리) → 학생별 클래스 → 세트**.
  앱의 「클래스카드는 교재에 붙는다」 가설과 결이 같다 — 교과서 클래스 하나에
  그 교재의 단어·문장 세트가 과(Lesson)별로 들어 있다.
- 학생 계정 예: 김서은 = chloe6120 (앱의 `chloe+뒷번호` 규칙과 동일 계열).

## 2. 단어 세트 — 학습 모드와 학습효과

카드는 「학습구간」(10개 단위)으로 잘려 구간별로 학습한다.

| 모드 | 방식 | 학습효과 |
|---|---|---|
| 암기학습 | 카드 앞면(단어)+발음 자동재생 → 커버 열어 뜻·예문 확인 → **「이제 알아요」/「나중에 한번 더」** | 인지 단계. 모르는 카드만 반복 (자기평가 기반 선별) |
| 리콜학습 | 단어 제시 → **4지선다**로 뜻 고르기 (키보드 숫자 지원) | 재인(recognition) 확인 |
| 스펠학습 | **발음만 듣고 철자 입력** (힌트 가능) | 회상(recall)+철자. 받아쓰기 효과 |
| 스피킹 | 마이크로 발음 (문장 세트에서 확인, 단어도 동일) | 발화 훈련 |
| 매칭 | 짝맞추기 게임 | 반복을 게임화 |
| 테스트 | 문항 자동생성 시험 (아래 §3) | 평가·기록 |
| 퀴즈배틀/크래시/슬라이드 | 게임·수업용 표시 | 수업 중 활동용 |

**필수학습 지정**: 학습/테스트 설정에서 모드별 토글. 지정하면 학생 화면에
「필수」로 뜬다 (원장님 세트들은 현재 대부분 「자율」, 문장 세트 일부는
스피킹이 「필수」로 지정돼 있었다).

## 3. 테스트 설정 (학습/테스트 설정 → 세트별 또는 일괄 적용)

- **객관식 자동생성**: 단어제시→의미선택 · 의미제시→단어선택 · 발음제시→의미선택 ·
  예문제시→단어선택, 4/6지선다 선택.
- **주관식 자동생성**: 단어제시→의미입력 등 4방향. 채점을 **AI 채점 / 부분일치 /
  완전일치** 중 선택 (+ 첫글자만 입력 문항, 엄격 채점 옵션).
- **진행 방식**: 답안 입력 시간 제한, 응시제한 횟수(무제한~), **직전 오답만
  출제하기(= 재시험이 1차 오답만 다시 나옴, 만점까지 반복)**, 비밀번호,
  제출 후 5분 학습 후 재응시 허용.
- 앱과의 접점: 「직전 오답만 출제」가 앱의 재시험 셈법(통과/재시험 통과/3차 통과)과
  자연스럽게 맞는다.

## 4. 드릴 세트 — 11개 문항 유형 (전부 확인)

1. 객관식
2. 주관식
3. 번호선택 (T/F 포함)
4. 객관식 빈칸 (드롭다운)
5. 주관식 빈칸 (직접 입력)
6. **틀린부분 1개 고치기**
7. **틀린부분 여러개 고치기**
8. **어순배열** (단어 배열)
9. **순서배열** (문장·문단 배열)
10. **표시부분의 문장성분 맞추기** (밑줄 친 부분 = 주어/동사/목적어?)
11. **문장에서 주어·동사 등 찾기** (문장성분 직접 지정)

- 문항 통째 붙여넣기 자동입력(밑줄 포함), 선택지 자동추출, 이미지 첨부,
  해설 입력, **AI 문항 생성**, 문항/정답 일괄 입력.
- 학습효과: 어법 수정·문장성분·배열 유형이 있어 **내신 어법/서술형 대비 문제풀이**를
  클래스카드 안에서 낼 수 있다. 앱의 english-exam-authoring(변형문제) 결과물을
  드릴 세트로 옮겨 숙제화하는 연결도 가능해 보인다.

## 5. 문장 세트 — 모드

- 끊어읽기 세트: 본문이 의미단위(/)로 잘린 카드.
- 하단 모드: **직독직해 · 암기 · 리콜 · 스펠 · 스피킹 · 스크램블 · 테스트**.
- **직독직해(슬라이드)**: 탭 3개 —
  - **입해석**: 영어 보고 해석 말하기(해석은 가려져 있고 열어 확인, 모르는 단어
    shift+click 사전)
  - **입영작**: 한글 보고 영어 말하기
  - **어순배열**: 한글 제시 + 영어 단어칩 배열 (**통문장 어순배열 고난이도** 옵션)
- 학습효과: 본문 암기(내신 대비 본문 시험)에 직결 — 해석↔영작 양방향 + 어순 감각.
- 원장님 실사용: 같은 Lesson에 「끊어읽기」 세트와 「본문」(문장) 세트 두 벌,
  + 별도 「순서배열」 세트(3~7카드), 백발백중 단어 세트.

## 6. 리포트 — 선생님이 학생 결과를 보는 화면 (있다)

- 클래스마다 탭: 세트 / 학생 / **리포트** / 관리.
- 리포트 하위: **세트 학습현황 / 학생 학습현황 / 학원 리포트** + 정렬·숨긴 세트 필터.
- 학생 행마다: **성적표 · 오답노트 · 초기화**, 기간 필터(날짜 선택).
- **학습진도 정의(완료 기준)**: 「세트의 카드 중 해당 학습을 마친 카드의 비율.
  암기학습 70% = 카드 중 70%를 아는 카드로 표시. **200% = 그 학습을 2회 반복**」.
- **성적표**: 학생별 인쇄/공유용 리포트. 표시항목 선택(스피킹·암기·리콜·스펠·
  매칭/스크램블 최고·반복횟수·테스트 1차/최고/최종), 테스트 미응시 0점 제외 옵션,
  **카카오톡 등으로 보내기 / 인쇄**. 학원 로고(클로이영어)가 박혀 나온다.
- 엑셀 저장 있음 → **데이터를 밖으로 뺄 수 있다** (앱 연동 시 수동 경로로라도 활용 가능).
- 오답노트: 학생별 오답 모음. 「누적 오답 단어 복습하기」 세트(누적기간 표시)가
  클래스 맨 위에 자동으로 붙어 있다 — 누적 오답 재학습 루프.

## 7. 앱/루틴 설계에 걸리는 시사점

1. 원장님 루틴 메모의 「클래스카드 문법훈련」 「클래스카드 - 듣기 10문제」는
   각각 별도 제품(문법훈련·듣기훈련) 또는 카테고리 클래스로 이미 쓰고 있다.
2. 숙제 항목 ↔ 클래스카드 매핑 후보:
   - 단어 숙제 = 단어 세트 (구간 단위, day 순환은 세트/구간 선택으로)
   - 본문 숙제 = 문장 세트 (입해석/입영작/어순배열)
   - 어법·서술형 문제풀이 = 드릴 세트 (11유형, AI 생성)
   - 재시험 = 테스트 「직전 오답만 출제」
3. 완료 판정: 모드별 진도율(%) + 테스트 점수(1차/최고/최종)가 있으므로,
   앱의 「완료/미흡/미이행」과 대응시킬 수 있다 (예: 필수학습 100% = 완료).
4. 성적표가 카카오톡 공유·인쇄를 지원하므로 데일리리포트에 붙일 근거 자료로 쓸 수 있다.

## 7-1. 플래너 (2026-08-13 확인) — 정규 단어숙제는 여기서 돈다

원장님: 「학생별로 정규단어암기는 숙제가 다르고 (플래너 활용)」

- 위치: **학원관리 → 클래스카드 플래너 리포트** (`/Pro/ReportAllPlanner`).
  학원관리에는 그 밖에 전체 학생/세트별/클래스별 리포트 · 문법훈련 리포트 ·
  학생/선생님 관리 · 학원 브랜딩이 있다.
- 구조: **학생 선택 → 달력에 마감일**(예: 공시연은 화·목) → 마감일을 누르면
  그날 마감인 **세트 목록이 클래스별로** 나온다.
- 예 (공시연, 8/11 마감): 클래스 「단어 - 보카 익스프레스 - 수능필수」 →
  VOCA EXPRESS 고등 Part 2. Day 01~04, 전부 ✅완료.
- 줄을 펼치면 **지정된 학습모드와 진도율**이 나온다 (예: 「리콜 8/11 100%」).
  → **플래너 숙제 = 세트+모드+마감일, 완료 판정 = 지정 모드 진도 100%.**
- 앱 연동 시사점: 학생별 정규 단어숙제(단어장·Day·요일)는 클래스카드 플래너가
  이미 원본이다. 앱이 중복 관리하면 두 벌이 된다 — 앱은 「클래스카드 플래너 완료
  여부」를 확인·기록하는 쪽이 맞아 보인다 (원칙 1).

## 9. 원장님 답변 기록 (2026-08-12, 루틴 브레인스토밍)

> Q. 문법 10개 항목을 한 단원에 몇 번 수업으로 나누나? 집/학원 구분은?
> A. **「그냥 그 사이클이 다 안된걸 집에서 하는거고, 구두테스트는 등원해서,
> 셀프녹음테스트는 집에서 그 차이야.」**

해석: 문법 루틴은 「회차별 고정 분배」가 아니라 **한 사이클(체크리스트)을 수업에서
진행하다 남은 것이 그대로 숙제가 되는 구조**. 유일한 집/학원 구분은
구두테스트(등원) ↔ 셀프녹음(집) 짝 — 앱의 `home_item_id` 짝 구조와 정확히 일치.
