# 1. 지금 돌아가는 것 (8/14~16 에 만든 것)

## 발송 — 이번 주에 제일 많이 바뀐 곳
- **「보낼 것」 이 발송 첫 화면** (`/report`, SendTodo). 리포트(수업일별)·
  교재 안내(학생별, 사용 예정일 표시)·월간(월말 3일 전부터)이 체크된
  채로 모이고, 「지금 보내기」 또는 「이 시각에 예약」.
- **예약 발송** (0126 scheduled_sends). 때가 되면 ① 직원이 앱을 열 때
  (대시보드·발송에서 runDueSends) ② `/api/cron/send` 를 바깥 크론이
  두드릴 때 나간다. 크론은 서버 열쇠(lib/supabase/admin)로 돌고,
  resend·sendNotices·pushToFamilies 는 `supa` 인자로 그 열쇠를 받는다.
  Vercel 자체 크론(하루 1번)은 vercel.json 에.
- **교재 안내 안 놓치기** (0125 student_textbooks.notified_on).
  「사용 예정인데 안내 안 나간 것」 이 발송 안내 탭 확인 목록 + 메뉴
  배지(report 키 합산)로 선다. 안내를 보내면 notified_on 이 새겨져
  빠진다. 받는 사람을 고르면 예정 교재가 문구에 자동으로 채워진다
  (재원생 = 사용 예정, 상담자 = 0122 book_ids).
- **경로 규칙**: 재원생 = 앱 알림만. 신규(상담 q: + **첫 등원 전인
  재원생 s:**) = 문자·알림톡. 첫 등원 전 판정은 enrolled_on > 오늘.
- **문구**: 설정 → 문구의 편집기 재마운트(포커스 풀림) 수리, 숨긴 문구
  되살리기/완전 삭제, 갈래 분류(재원생-앱 / 신규-문자), 발송 화면에서
  이름·분류 편집. 변수 채우기는 `lib/noticeFill` 한 곳.

## 학생·학교·시작일
- **시작일은 enrolled_on 하나** (0127 — started_on 과 합침). 수강료
  일할(lib/tuition)·등록 3경로·전환·대시보드 전부 이 칸. lib/tuition·
  lib/firstDay 에만 0127 전 폴백.
- **첫 등원 달력은 베끼지 않는다** (lib/firstDay). tasks 복사를 걷어냈고,
  할일·달력·대시보드가 enrolled_on 을 그 자리에서 읽는다.
- **학교 잇기** (lib/schoolLink, C7). 등록·수정·엑셀·전환이 저장할 때
  school_id 를 잇는다 — 엄격 키 먼저, 안 되면 지역 떼고(sameSchool)
  하나로 떨어질 때만. 과거분은 학교 명단 「안 이어진 학생 잇기」.
  「시험 회차 없음」 경고는 초등을 빼고, 학교마다 「나이스 코드 없음」
  을 붙여 왜 안 잡히는지 말해준다.
- **교재 삭제·절판·중단 잠금**: 쓰는 재원생(사용 예정 포함)이 있으면
  서버가 거절하고 누가 쓰는지 알려준다 (inUseBlockers).
- **상담 교재**: 0122 book_ids(안내 역기록·등록 전환 자동 배정) +
  0128 book_start_on(안내에 적은 예정일 — 전환이 그 날짜로 배정).
