# 알림톡 연결 · 할일 제목에 단원

관련: [[2026-07-27-문자문구]] · [[2026-07-27-숙제에서-내할일]]

---

## 1. 할일 제목 — 여기는 코드가 필요했습니다

`{학생}-단원평가-{단원}` 처럼 쓰시려면 **`{단원}` 이라는 자리 자체는 코드가 알아야** 합니다.
문구는 DB에 있지만, "단원이 뭔지 어디서 가져오나" 는 코드가 압니다.

그래서 자리를 네 개 만들었습니다.

| 자리 | 들어가는 것 |
|---|---|
| `{학생}` | 학생 이름 |
| `{단원}` | 그 숙제에 붙여준 단원. 여럿이면 쉼표로. 단원을 안 고르고 범위만 적었으면 그 글자 |
| `{교재}` | 단원이 속한 교재 |
| `{숙제}` | 숙제 항목 이름 |

```
{학생}-단원평가-{단원}
  → 김O윤-단원평가-Chapter 3 관계대명사
  → 김O윤-단원평가                    (단원을 안 붙였을 때)
```

값이 비면 **앞뒤 구분자까지 정리**됩니다. `-단원평가-` 뒤에 아무것도 없이 끝나지 않습니다.

기본값도 `{학생}-단원평가-{단원}` 으로 바꿨습니다 (직접 고치셨으면 그대로 둡니다).

## 2. 알림톡 연결

### 필요한 것

| | 어디서 |
|---|---|
| 발신프로필 ID (pfId) | 솔라피 → 카카오 채널 연결하면 나옵니다 |
| 템플릿 코드 | 카카오 승인 났을 때 받는 코드 |
| 템플릿 원문 | 승인받은 그 문구 (복사해두세요) |

### 붙이는 법

**설정 → 발송·연동 설정** 에 `pfId` 를 한 번 넣습니다.

**설정 → 문자 문구 → (문자 하나) → 수정 → 알림톡**

1. **템플릿 코드**를 넣습니다
2. **템플릿 원문을 그대로 붙여넣습니다** — 앱이 `#{변수}` 를 찾아냅니다
3. 각 변수를 앱의 어떤 값에 붙일지 **고릅니다**

```
승인받은 템플릿
  [클로이영어] #{학생명} 학생 #{날짜} 수업 안내
  #{내용}
  문의 #{전화}

붙이기
  #{학생명}  ←  {{학생명}}      학생 이름
  #{날짜}    ←  {{날짜}}        그 날짜
  #{내용}    ←  {{본문내용}}    앱이 만든 문구에서 맨 윗줄을 뺀 것
  #{전화}    ←  {{학원전화}}
```

원문은 **저장하지 않습니다.** 변수를 찾는 데만 씁니다.

### 앱이 내어줄 수 있는 값

| | |
|---|---|
| `{{학원명}}` `{{학생명}}` `{{날짜}}` | 그대로 |
| `{{본문}}` | 앱이 만든 문구 **전체** (제목 포함) |
| `{{본문내용}}` | 맨 윗줄(제목)을 **뺀** 것 |
| `{{학원전화}}` `{{학원주소}}` | 설정에 적어둔 것 |

**`{{본문}}` 과 `{{본문내용}}` 중 고르는 게 중요합니다.**
템플릿에 이미 `[클로이영어] #{학생명} 학생 …` 이라는 제목 줄이 있으면 `{{본문내용}}` 을,
템플릿이 `#{내용}` 하나뿐이면 `{{본문}}` 을 붙이세요. 안 그러면 제목이 두 번 나옵니다.

내가 쓰는 문자(교재 안내 등)는 **그 문자에서 채운 `{{변수}}` 도 그대로 붙일 수 있습니다.**

### 종류마다 따로

템플릿 코드를 안 넣은 문자는 **지금처럼 문자로** 나갑니다.
데일리리포트만 알림톡, 나머지는 문자 — 이런 것도 됩니다.
문자 문구 목록에 `알림톡` / `문자` 로 표시됩니다.

### 실패하면 문자로

`disableSms: false` 로 보냅니다. 알림톡이 막힌 번호(수신 거부·미가입)에는
**같은 내용이 문자로 대신** 나갑니다. 그래서 알림톡을 쓰더라도 앱이 만든 문구는 항상 채워 보냅니다.

## 확인하는 법

| 보이면 | 된 것 |
|---|---|
| 설정에 `알림톡 발신프로필 ID (pfId)` 칸 | 배포 반영 |
| 문자 문구 수정에 `알림톡` 칸 | 0030 실행됨 |
| 문자 이름 옆 `알림톡` 초록 태그 | 그 문자는 알림톡으로 나감 |
| 할일 제목에 단원이 붙음 | 0030 실행 + 다시 배정 |

이미 만들어진 할일 제목은 **바뀌지 않습니다.** 만들 때 정해지기 때문입니다.
다음에 배정하는 것부터 단원이 붙습니다.
