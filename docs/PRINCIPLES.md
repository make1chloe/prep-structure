# 설계 원칙 (반드시 지킬 것)

이 문서의 원칙은 기능보다 우선한다. 새 화면을 만들기 전에 항상 여기부터 확인한다.

---

## 원칙 1. 같은 값을 두 번 입력하지 않는다 (Single Source of Truth)

하나의 값은 **한 곳에서만 입력**하고, 나머지 화면은 그 값을 **참조**한다.

### 지켜야 할 것

- 학생 이름·연락처는 `students`에만 있고, 리포트·출결·상담은 학생을 **연결**만 한다.
- 교재/단원은 `textbooks`·`textbook_units`에만 있고, 진도·리포트는 **선택**만 한다.
- 반의 요일·시간은 `classes`에만 있고, 출석부·시간표는 그걸 **읽어온다**.
- 학생별 진도는 한 번 기록하면, 데일리리포트·월말리포트·학부모 안내가 **같은 값을 재사용**한다.

### 하지 말아야 할 것

- 노션처럼 리포트에 교재명을 **텍스트로 다시 적기**
- 반 정보를 출석부 화면에서 **또 고르게 하기**
- 같은 숙제 항목을 화면마다 **다르게 나열하기** → 항목 마스터(`homework_items`) 하나만 사용

### 자동으로 흘러가야 하는 값

| 한 번 입력 | 자동으로 쓰이는 곳 |
|---|---|
| 학생 정보 | 출석부 · 리포트 · 상담 · 학부모 안내 · 로그인 계정 |
| 반 요일/시간 | 오늘 수업 목록 · 출석부 · 시간표 · 보강 안내 |
| 교재·단원 | 진도 입력 · 리포트 진도 문구 · 교재별 진도 현황 |
| 오늘 진도·숙제 | 데일리리포트 문구 · 다음 수업 숙제 · 월말 리포트 |
| 출결 기록 | 월별 출결 집계 · 결석/보강 안내 · 수납 계산 |
| 테스트 점수 | 리포트 문구 · 성적 추이 · 재시험 대상 추출 |

## 원칙 2. 선생님이 화면을 이동하지 않게 한다

수업 중에는 화면을 옮길 여유가 없다. **한 화면에서 그날 일이 끝나야 한다.**

### 화면 구성 규칙

1. **탭·페이지 이동 대신 한 화면 안에서 펼치기**
   - 입력 폼은 접이식 패널로 목록 위에 둔다 (이미 적용: 학생·교재 엑셀 추가)
   - 상세 보기는 새 페이지가 아니라 **옆 패널 또는 같은 줄 확장**
2. **목록에서 바로 수정** — 행을 클릭하면 그 자리에서 편집 (이미 적용)
3. **오늘 할 일이 첫 화면에** — 로그인하면 오늘 수업·오늘 출석·미작성 리포트가 바로 보인다
4. **선택 후 일괄 처리** — 한 명씩 반복하지 않고 여러 명을 한 번에 (이미 적용)
5. **자주 쓰는 값은 미리 채워둔다** — 지난 수업 진도, 학생별 기본 숙제 개수 등

### 핵심 화면: 수업 화면 (3단계에서 만들 것)

한 화면에서 다음이 모두 끝나야 한다.

```
[오늘 · 월수 7:30반]                          [저장]
──────────────────────────────────────────────
학생     출결    단어T    문장T   숙제(완료/미흡/미제출)  태도  진도
홍길동   정시    18/20    9/10    [항목 칩 클릭]         ⭐⭐⭐⭐  Unit 3
김철수   지각    15/20    ...
```

- 학생 줄 × 항목 열의 **표 하나**
- 숙제 항목은 칩(chip)을 눌러 완료→미흡→미제출로 순환
- 진도는 지난 수업 값이 **미리 채워져** 있고, 바뀔 때만 수정
- 저장하면 그 데이터가 리포트 문구·출결 집계·다음 숙제로 **자동 연결**

---

## 원칙 3. 자동화는 데이터가 흐르게 만드는 것

발송이나 알림보다, **한 번 입력한 값이 다음 단계로 저절로 넘어가는 것**이 먼저다.

| 흐름 | 자동 처리 |
|---|---|
| 수업 입력 → 리포트 | 문구 자동 생성 (선생님은 확인만) |
| 오늘 숙제 → 다음 수업 | 미제출 항목이 다음 수업 화면에 자동 표시 |
| 출결 → 안내 | 결석 시 보강 안내 대상 자동 추출 |
| 테스트 미통과 → 재시험 | 재시험 대상 목록 자동 생성 |
| 진도 → 교재 종료 예상 | 남은 단원으로 교재 소진 시점 자동 계산 |

---

## 원칙 4. 그 밖의 확정 사항

1. 화면을 만들기 전에 **DB 속성을 나열하고 불필요한 것을 제거**한다.
2. 입력은 **엑셀 양식 다운로드 → 파일 업로드**를 기본으로 한다.
3. 모든 목록은 **전체/일부 선택 → 수정·삭제·변경·이동**이 가능해야 한다.
4. 학생 로그인 아이디는 `chloe + 전화 뒷자리 4`, 충돌 시 `-2`, `-3`.
   기본 비밀번호 `0000`, 첫 로그인 후 학생이 변경.
5. 노션의 수식·롤업·버튼은 저장하지 않고 앱 기능으로 대체한다.
6. 자주 바뀌는 항목(숙제 종류 등)은 컬럼이 아니라 **마스터 테이블**로 둔다.
7. UI 문구는 **선생님이 쓰는 말**로 쓴다. (설명용 단어를 화면에 그대로 쓰지 않기)
8. 여백보다 **한 화면에 담기는 정보량**을 우선한다.
