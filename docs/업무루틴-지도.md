# 업무루틴 지도 (MOC)

클로이영어 앱과 문서에서 뽑아낸 **원장님의 실제 업무 루틴**을 여섯 층위로
나눠 적은 노트 묶음의 입구다. 앱 화면·코드·원장님 말씀에서 확인된 것만
적었고, 각 노트 끝에 「어디에 사는가」 표를 붙여 앱과 이 문서가 함께
움직이게 했다.

**엄격하게 지키는 규칙(대전제·소전제)은 [[업무루틴-규칙]] 한 곳에 모았다** —
층위 노트와 어긋나면 그 노트와 출처가 이긴다.

| 층위 | 노트 | 한 줄 요약 |
|---|---|---|
| 규칙 | [[업무루틴-규칙]] | 대전제 15 · 영역별 소전제 — 반드시 지키는 것 |
| 학기 | [[업무루틴-학기별]] | 내신 두 번 · 모의고사 · 방학 특강이 만드는 큰 리듬 |
| 달 | [[업무루틴-월별]] | 25일 회차 확정 → 월말 월간리포트 → 월초 경고 정리 |
| 주 | [[업무루틴-주별]] | 월~목 정규 · 금 보강 전용, 주 단위로 도는 신호들 |
| 하루 | [[업무루틴-일별]] | 대시보드(알림센터) → 수업 → 하원 → 발송 |
| 수업 | [[업무루틴-수업별]] | 학생 한 명 판의 처리 순서와 교재별 루틴 |
| 재원생 | [[업무루틴-재원생별]] | 문의→상담→등록→재원→퇴원, 아이마다 도는 축 |

## 이 루틴 전체를 관통하는 원칙 (자세한 것은 [[업무루틴-규칙]])

1. **기억하지 않는다 — 화면이 재촉한다.** 해야 할 일은 배지·카드·배너로
   앱이 띄운다 (대시보드 = 알림센터, [[dashboard-principles]] A1).
   루틴의 절반은 「앱이 띄운 것을 그날 처리하는 것」이다.
2. **한 번 입력하면 끝까지 흐른다** ([[PRINCIPLES]] 원칙 1).
   수업 중 입력 가운데 검사·출결·단어시험·단원평가는 데일리리포트를 거쳐
   월간리포트까지, 진도는 데일리리포트(학부모 화면·문자 문구)까지, 성적
   입력(내신·모의)은 성장 카드와 상담 문구까지 재사용된다 — 어느 갈래에도
   같은 값을 두 번 적는 자리가 없다.
3. **틀린 재촉은 안 뜨느니만 못하다.** 못 세면 0, 늘 켜진 재촉은 없는 것과
   같다 — 그래서 월간리포트는 월말 3일 전부터만, 단원평가 막힘은 3회부터만
   알린다.
