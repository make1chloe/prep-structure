# 값 → 사용처 지도 (원칙 1 소급 전수검사)

> 원장님: 「원칙 1, 앞으로 입력칸 만들 때가 아니라 **지금 만든 것도 전수
> 사용처를 작성하고 연결 검사해**.」

모든 입력 칸에 대해 「어디서 적고 → 어디서 쓰이나」 를 네 갈래(학생 ·
상담/설문 · 교재/단원/반 · 수업기록/일정)로 전수 조사한 결과.
**문제만 적는다** — 잘 흐르는 칸은 각 절 끝에 이름만. 고치면 ✔.

## P0 — 돈·프라이버시·거짓 약속 (지금 고칠 것)

- [x] P0-1. **score_share 가 발송을 안 막던 것** — 학부모 비공개면 월간
      문구에서 점수 절이 빠지고, 발송 화면에서 「점수 빼고 보냄 /
      보내지 않음」 을 고른다 (원장님 「선택 가능하게」). ✔ 2026-08-15.
      남은 조각: 재원생 화면에서 공개 설정 바꿀 자리 (지금은 성적 화면만).
- [x] P0-2. **등록 시작일이 수강료로 안 흐른다** — enrolled_on(등록)과
      started_on(일할계산)이 두 칸인데 복사가 없어 **월중 입회도 만액**.
      퇴원 처리도 ended_on 을 안 채워 일할 안 됨. ✔ 등록 3경로가
      started_on 도 채우고, 퇴원 전환이 ended_on 을 채움 (2026-08-15)
- [x] P0-3. **"학생공지" 칸은 적어도 아무 데도 안 나간다** — 화면은 「숙제
      안내 맨 위에 들어갑니다」 라고 약속하는데 reportData·reportText 가
      안 읽고, 오늘 수업 재열람 때도 사라진다. ✔ 숙제 안내 맨 위 +
      리포트 본문 + 재열람 복원 (2026-08-15)
- [x] P0-4. **교재 안내 문자에 첫 권 구매링크만 나간다** — 여러 권이면
      나머지 링크 유실. ✔ 전권 「교재명: 링크」 줄로 (2026-08-15)
- [x] P0-5. **테스트 발송과 실제 발송이 다른 번호로 간다** — 실제는 부모
      번호만, 테스트는 학생번호 우선. ✔ 테스트도 부모 번호 우선 (08-15)
