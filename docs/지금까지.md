## 돌리는 법

- 검사 전부: `bash scripts/check-all.sh` (검사 + 빌드). 화면 검사만: `node scripts/check-{palette,mockup,sizes,fonts,contrast}.mjs`
- 눌러보기: `bash scripts/e2e/run.sh` → 내리기 `bash scripts/e2e/down.sh`. 앱 화면이 늘면 `run.sh` 의 `CHECK_URLS` 에 주소를 더한다.
- 목업을 고친 날: `node scripts/mockup-css.mjs` → `check-all` → 아티팩트 다시 올리기 (`docs/목업/README.md`)
