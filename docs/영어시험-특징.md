# 영어 시험의 특징 — 시험대비 페이지를 만들 때 볼 것

> 2026-08-09, 원장님 — 「지금 알게 된 영어 시험의 특징을 따로 문서로
> 정리하고, 나중에 시험대비 페이지 만들 때 참고해」
>
> 제도 전반과 일정 규칙은 `docs/시험-일정-조사.md` 에 있다. 이 문서는
> **영어 과목에만 있는 특징**과, 그것이 시험대비 페이지의 어떤 화면 조각이
> 되어야 하는지를 적는다. 전부 이번(2026-08) 작업에서 원장님 말씀과 실제
> 데이터로 확인한 것들이다.

## 1. 시험 기간과 영어 시험일은 다르다 — 날짜가 두 겹이다

내신 시험 기간은 2~5일이고 과목별로 하루씩 본다. **영어는 그중 하루**다.

- 학교가 알려주는 것은 처음에는 **기간뿐**이다 (나이스도 기간만 준다).
  영어가 몇째 날인지는 시간표가 나와야 알고, 원장님이 손으로 채운다
  → `exam_periods.english_on` (2단계 입력: ① 기간 → ② 영어 시험일).
- 대비의 마감은 시험 시작일이 아니라 **영어 시험일**이다. 자료·마무리
  수업·파이널이 전부 이 날짜에 매달린다.
- **영어 시험일 전날은 정규수업이 아니어도 등원**한다 (`eveDate` 알림).
- 시험 기간 중 영어 시험일이 아닌 날은 **타과목 시험 때문에 결석 예상**으로
  잡는다 — 영어 수업 회차 계산에서 빠지고, 보강 대상도 아니다.
- 모의고사는 하루짜리라 **그날이 곧 영어 시험일**이다 (기계가 자동으로 채움).

시험대비 페이지에서: 회차마다 「영어 시험일까지 D-n」 이 기준 축이 되어야
한다. 영어 시험일 미정인 회차는 그 자체가 할 일(채워야 함)이다.

## 2. 범위의 단위가 특이하다 — 교재 단원 + 모의고사 문항

영어 내신 범위는 다른 과목과 달리 **여러 종류의 자료가 섞인다**:

- 교과서 몇 과 + 부교재(모의고사·EBS 지문) + 프린트.
- 학교가 「3월 모의고사 18~24번」 처럼 **모의고사 문항 번호로** 범위를
  알려주는 일이 흔하다. 그래서 모의고사도 회차가 있어야 하고
  (`makeMockBook`), 문항이 단원처럼 담긴다 — **18~45번만** (1~17번은
  듣기라 내신 범위에 안 들어간다).
- 범위는 `prep_scopes` 에 교재 단원 단위로 담고, 재촉(`needsScope`)은
  내신에만 띄운다. 모의고사·수능·수행평가는 범위가 없다.

시험대비 페이지에서: 범위 등록이 곧 대비의 시작점. 범위에 담긴
단원·지문·문항 수가 대비 분량이고, 「범위 미등록」 이 첫 번째 재촉이다.

## 3. 시험마다 다른 것 — 출제 선생님·등급컷·특이사항

같은 학교라도 **회차마다** 다르다. 학교 단위가 아니라 회차 단위로 적는다:

- **출제 선생님** (`teachers[]`) — 학년별로 나눠 내거나 공동 출제라 여러
  명일 수 있다. 선생님이 누구냐가 문제 스타일(어법 비중, 서술형 유형)을
  결정하므로 기출 분석의 열쇠다.
- **등급컷** (`cuts[]`) — 1등급컷부터 높은 순서. 그 시험을 본 학생 전부의
  등급이 이 한 벌로 매겨진다. **내신에만 있다** — 모의고사는 전국 단위
  등급이 성적표로 오고, 학원이 컷을 정하지 않는다.
- **특이사항** (`note`) — 서술형 비중, 범위 밖 출제 습관 등. 이것만은
  모의고사에도 남긴다 (화면에서 등급컷·선생님 칸은 내신에만 낸다).

## 4. 점수의 뜻이 학교급마다 다르다

- **중학교** — 절대평가 (A~E, 90점 이상 A). 등급컷이 사실상 고정.
- **고등학교** — 상대평가 등급제. 등급컷이 시험마다 다르고, 문제를 일부러
  어렵게 내서 변별한다 (킬러 문항·서술형). 그래서 회차별 `cuts` 입력이
  필요하다.
- **모의고사** — 전국 백분위·등급이 나온다. 내신과 다른 잣대이므로 성적
  화면에서 섞어 평균 내면 안 된다.

## 5. 안 보는 회차가 체계적으로 있다

이름이나 날짜로 가를 수 없어서 **원장님이 표시**한다 (`exam_skips` —
성적 미입력 화면의 「안 봄」·「이 학년 안 봄」):

- 중1 — 자유학기제라 지필이 대부분 없다.
- 중3 2학기 — 고입 때문에 기말이 당겨지거나 생략.
- 고3 — 2학기는 수시 일정으로 중간만 9월에 보는 학교가 많고, 기말이 없는
  경우가 흔하다. 학교에 따라 고3만 다른 주에 따로 본다 (회차에 학년 표시).

시험대비 페이지에서: 「안 봄」 처리된 회차는 대비 목록·재촉·성적 미입력
어디에도 나오면 안 된다.

## 6. 학원의 대비 흐름 (일정 위주)

```
시험 3~4주 전   내신대비 시작 — 정규 진도 중단, 학교별 범위·기출로 전환
                (범위가 이때까지 등록되어 있어야 한다)
시험 1주 전     파이널 — 기출 변형·서술형·어법 마무리
영어 시험 전날  정규수업이 아니어도 등원 (전날 등원 알림)
시험 기간       타과목 날은 결석 예상 처리
시험 직후       성적 입력 → 등급컷 입력 → 오답 확인, 다음 회차로
```

시험대비 페이지가 이 흐름을 그대로 한 줄로 보여주면 된다 — 회차마다
「범위 → 자료 → 전날 등원 → 성적 → 등급컷」 이 어디까지 왔는지.

## 7. 이미 있는 데이터 (새로 만들지 말 것)

| 것 | 곳 |
|---|---|
| 회차·기간·영어 시험일·등급컷·출제 선생님·특이사항 | `exam_periods` |
| 시험범위 (교재 단원 단위) | `prep_scopes` |
| 모의고사 문항 교재 (18~45번) | `makeMockBook` → `textbooks/units` |
| 안 보는 회차 | `exam_skips` |
| 성적 | `scores` |
| 누가 이 시험을 보나 | `lib/who.takesExam` (학교+학년) |
| 시험 갈래 (내신·모의·수능·수행) | `lib/examKind.classifyExam` |
| 학기 묶음 (「26년 2학기 중간」) | `lib/examList.groupExams` |

시험대비 페이지는 이것들을 **읽어서 한 화면에 모으는 것**이지, 같은 속성을
새로 만드는 것이 아니다 — 두 벌이 되는 순간 언젠가 한쪽만 고치게 된다.
