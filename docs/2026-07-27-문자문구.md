# 문자 문구를 종류별로 · 전부 웹에서

관련: [[2026-07-27-숙제에서-내할일]] · [[2026-07-27-하원안내]] · [[미해결-클로이영어앱]]

---

## 코드에 박힌 것은 없습니다

`{학생} 단원평가 출제` 는 **DB 값**입니다. 코드에는 "단원평가" 라는 말이 없습니다.

| 하고 싶은 것 | 어디서 |
|---|---|
| 숙제 항목 추가·수정·삭제 | 교재 · 숙제 → **학습 항목** |
| 어떤 숙제가 할일을 만들지 | 같은 표의 **내 할일 자동 생성** 칸 |
| 문자 문구 추가·수정·삭제 | 설정 → **문자 문구** |
| 할일 분류 | 할일 화면에서 직접 |

SQL 이 하는 일은 **처음 한 번 자리를 만들어 두는 것**뿐입니다.
`단원평가` 가 들어간 항목에 기본값을 켜주고, 문자 9종의 초안을 넣습니다.
그 뒤로는 전부 웹에서 바꾸시면 되고, 다시 SQL 을 돌려도 이미 있는 것은 건드리지 않습니다.

## 문자 문구 (설정 → 문자 문구)

인삿말·맺음말이 **하나뿐**이라 데일리리포트에도, 숙제 문자에도, 하원 안내에도
같은 말이 붙었다. 종류마다 톤이 다른데 그럴 수가 없었다. 그래서 나눴다.

### ① 앱이 보내는 문자 — 인삿말·맺음말만

본문은 그날 입력한 내용에서 자동으로 만들어진다. 손댈 것은 앞뒤 인사뿐이고, 지울 수 없다.

| | |
|---|---|
| 데일리리포트 | 학부모 |
| 숙제 문자 (학생용) | 학생 |
| 늦은 귀가 안내 | 학부모 |

### ② 내가 쓰는 문자 — 본문을 직접

`발송 → 안내 문자` 에서 학생을 골라 보낸다. 얼마든지 추가·삭제할 수 있다.

| | 초안이 들어 있음 |
|---|---|
| 교재 구매 안내 | 있음 (전부터) |
| 레벨테스트 등원 / 하원 안내 | 있음 (전부터) |
| 지각 안내 | **새로** |
| 보강 안내 | **새로** |
| 단원평가 결과 안내 | **새로** |
| 신규 상담 · 레벨테스트 일정 안내 | **새로** |

초안은 말투만 잡아둔 것이니 원장님 말로 고쳐 쓰시면 됩니다.

## 변수 — 기능이 없는 문자도 지금 보낼 수 있게

지각·보강·단원평가 결과는 아직 **기능이 없습니다.** 기능을 다 만들려면 오래 걸리는데,
문자는 오늘부터 필요합니다. 그래서 **변수를 직접 채우는 길**을 열었습니다.

**자동으로 채워지는 것** (학생 정보에서 나옴)
```
{{학원명}} {{학생명}} {{날짜}} {{교재목록}} {{교재비}}
{{구매링크}} {{테스트결과}} {{학원주소}} {{학원전화}}
```

**그 밖에 무엇이든** — `{{시간}}`, `{{내용}}`, `{{점수}}` … 이름은 자유입니다.
자동으로 못 채우는 변수는 **보내기 전에 입력칸으로 뜹니다.**

```
보내기 전에 채울 것
  시간  [ 21:30            ]
  내용  [ 단원평가 18/20   ]
```

한 번 넣은 값은 **고른 사람 모두에게 똑같이** 들어갑니다.
학생마다 달라야 하면(단원평가 점수 같은 것) 한 명씩 보내면 됩니다.
안 채우고 보내려 하면 한 번 물어봅니다.

---

## 나중에 기능이 붙으면

지금은 변수를 손으로 채우지만, 아래는 자동으로 채워질 수 있는 것들입니다.
써보시고 손이 많이 가는 것부터 붙이면 됩니다.

| 문자 | 자동으로 채울 수 있는 것 |
|---|---|
| 지각 안내 | 출결을 '지각'으로 찍으면 → 시간까지 |
| 보강 안내 | 오늘 수업에서 보강을 잡으면 → 날짜·사유 |
| 단원평가 결과 | 점수를 입력하는 자리가 생기면 → 점수 |
| 상담 일정 | 신규 상담에 잡아둔 날짜 → 일시 |

## 저장 방식

`message_templates` 한 테이블에 다 있다 (0029에서 `key`·`greeting`·`closing` 추가).

- `key` 가 있으면 **앱이 본문을 만드는 문자** (report / homework / late). 본문을 고쳐도 안 쓰인다
- `key` 가 없으면 **내가 쓰는 문자**
- 삭제는 실제로 지우지 않고 `active=false`. 지난 발송 기록이 어떤 문구였는지 남아야 하기 때문

예전에 한 곳에 적어둔 인삿말·맺음말은 0029 에서 **데일리리포트로 옮겨진다.** 사라지지 않는다.
