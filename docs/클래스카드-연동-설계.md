전제 조사: 로컬 폴더 `클래스카드-조사-2026-08-12.md` (재조사 금지).
API 는 제공 안 함(원장님 확인) → **맥미니 상주 로봇**이 원장님 세션으로
내부 통신을 직접 호출하는 방식(b안)으로 간다. 비공식 접근이라 클카가

## 확정된 갈래 (원장님, 2026-08-16)

| 숙제 | 방식 | 원장님 손 |
|---|---|---|
| 정규 단어 | **A** — 플래너가 원본. 앱은 「오늘 마감 세트 완료 여부」만 읽는다. 세트명은 매칭이 아니라 **표시용** | 0 |
| 독해·본문 | **B** — 교재 단원 ↔ 클카 세트를 **한 번만 잇는 지도** (단원에 세트 id 칸). 이름 유사도로 후보 추천, 확정은 원장님 탭 | 교재당 1번 |
| 문법 암기 등 수시 | **B'** — 내주는 순간 그 학생 세트 목록에서 골라 붙임 + 검사 기준(모드·목표%). 글로만 적으면 유사도 매칭 — **하나로 딱 떨어질 때만** 자동, 아니면 「골라주세요」 (학교 잇기와 같은 규칙) | 내줄 때 탭 1~2번 |

검사 판정: 지정 모드 진도율 ≥ 목표(기본 100%) = ○, 일부 = △(%표시),
0 = ✕. 수업 시작에 맞춰 반별로 읽어 오늘 수업 검사 줄에 미리 찍는다.

## 필수 감시 두 가지 (원장님, 2026-08-16 — 「이건 꼭 필요한 기능이야」)

1. **플래너 ↔ 앱 단어 진도 불일치 경고.**
   앱의 단어 진도(회독·단원 체크)와 플래너가 돌고 있는 Day 가 어긋나면
   — 예: 앱은 Day 8까지 나갔는데 플래너 마감은 아직 Day 4, 또는 반대 —
   대시보드와 오늘 수업 그 학생 줄에 「클카 플래너와 어긋남 (앱 Day 8 ·
   플래너 Day 4)」 로 띄운다. 판정은 단원 이름 정규화(Day/Lesson 숫자
   추출) 한 곳에서.
2. **플래너 소진 경고.**
   학생의 플래너 마감일이 앞으로 없거나 마지막 마감이 3일 안이면
   「플래너 새로 잡아야 함」 — 대시보드 경고 + 발송 「보낼 것」 화면이
   아니라 **할일**(수업 준비)로 자동 생성. 단어 교재가 끝나가는 것
   (대시보드 「곧 끝나는 교재」)과 나란히 보이게 한다.

## 만드는 순서

1. **로봇** (맥미니, 원장님과 세팅 — 클카 로그인 1회):
   로그인 세션 유지 → 반 시간표(앱)를 읽어 수업 전+수업 중 주기로
   플래너 리포트·세트 목록·진도율을 긁어 앱 수신 주소로 전송.
   비번은 맥미니에만 저장, 서버(Vercel)에는 안 올린다.
2. **앱 수신 + 저장** (0131 예정): classcard_sync(학생×세트×모드 진도,
   받은 시각) + 수신 주소(비밀키). 「마지막으로 받아온 시각」 표시.
3. **A 자동판정** — 오늘 수업 단어 숙제 줄에 플래너 완료 여부 자동 ○△✕.
4. **감시 두 가지** (위 필수) — 대시보드·오늘 수업·할일.
5. **B 지도** — 교재 단원 잇기 화면(추천+확정). **B'** — 배정 때 세트 선택.

## 앱이 하지 않는 것

- 플래너 설정 자체(마감일·세트 지정)는 클카에서 — 원본이 거기다 (원칙 1).
- 세트 내용 미러링·복제 금지 — 완료 여부와 진도율만 읽는다.
