# 업무루틴 — 수업별 (학생 한 명 판)

> [[업무루틴-지도]] · 지키는 규칙: [[업무루틴-규칙]] §수업·검사 · §학습 루틴 · 위 층위: [[업무루틴-일별]] · 다음: [[업무루틴-재원생별]]
> 루틴 원본(구술 그대로): [[루틴-받아적기]] · 확정 근거: [[기본학습-정리-2026-08-14]]

수업의 단위는 「학생 한 명 판」 이다. 학생이 오는 순서대로 판을 열고,
저장하면 완료로 내려간다. 판의 순서는 **수업 흐름 그대로**다 (0118 재정비 +
8/19~21 개편, `app/today/StudentPanel.jsx` 실제 렌더 순서 기준).

## 1. 판의 처리 순서

```
① 출결 (정시/지각/결석/보강/조퇴/온라인 — 한 탭)
② 클카 — 그날 마감 세트별 ✅❌ (자료 있을 때)
③ 등원 — 학생 등원 체크(핸드폰·출석·숙제)를 대신 찍기 + 단어시험 시점
   (수업 시작에 / 다 끝내고 — 학생 화면 순서가 이걸 따라간다)
④ 낸 것 · 말할 것 (제출물 · 전달사항)
⑤ 테스트 — 단어 · 문법: 틀린 개수만 넣으면 맞은 개수·% 자동.
   **통과/미통과 자동 판정은 단어만** (통과선: 학생 것 → 없으면 설정 기본.
   통과 여부는 저장 안 함 — 매번 계산). 점수 칸 옆 「재시험 건너뛰기」 —
   오늘만 재시험에서 빼고(하원 사유·문자에서도 빠짐) 점수 기록은 그대로
⑥ 단원평가 — 단원명 + 통과/재시험 (단원명을 적은 것만 성적으로 흘러간다 —
   점수는 ⑤ 테스트의 문법 칸이 담당)
⑦ 숙제 검사 ○△✕
   · 1차 판단은 자동 채움: 클카 판정 + 학생 제출물 + 「다 했어요 ○로
     채우기」 — 「자동」 태그, **저장해야 확정**
   · 안 해온 숙제 처분: 「오늘수업으로」 / 「숙제 다시」 (항목별 기본 처분)
   · 검사 안 한 항목은 다음 수업으로 넘어간다 (바빠서 못 봐도 안 사라짐)
⑧ 등원 학습 — 순서 목록 (↑↓ · ✕ · 「다음수업」 · 「숙제로」)
   · 소화량 게이지: 학생별 8주 타이머 실적으로 넘치면 「숙제로 돌리기」 제안
   · 줄 끝의 「⟳ 루틴 다음」 버튼 — 누르면 그 학생 차례의 등원 항목·숙제·
     범위가 함께 채워진다 (applyRoutine)
⑨ 진도 — 끝낸 단원 체크 (회독별로 쌓인다), 진도 메모
⑩ 다음 — 다음 숙제 배정 (「⟳ 지난번과 같게 (단원은 다음 것)」)
⑪ 집중도 · 이해도 별점 (고른 것만 리포트에 나간다)
⑫ 공지 → 댓글 → 늦귀가 → 다음 수업 계획(plan_next) → 하원 안내 →
   경고(있을 때만) → 재시험 · 보강
```

- **임시저장** — 다 저장하되 완료로 안 넘긴다 (수업 중 끊겨도 안 날아감).
  저장 줄은 화면 아래 고정(.savebar).
- 저장 시 푸시는 두 갈래: 숙제가 배정돼 있으면 학생에게 숙제 알림이 나간다
  (바뀐 항목이 있으면 「숙제가 바뀌었어요」 로 그 항목부터). 오늘 등원 학습
  목록은 **순서까지 비교해 정말 바뀐 경우에만** 「오늘 할 일이 바뀌었어요」.
  둘 다 30분 단위(:00/:30) 배치.

## 2. 루틴이 채우는 것 — 「⟳ 다음」 의 뒤

- **루틴은 교재별**이다 (학생별 아님). 학생의 현재 단계는
  `student_textbooks.routine_step_id` 가 기억하고, `routine_step` 번호는
  재주입(rebuild) 뒤에도 위치를 잃지 않기 위한 폴백이다.
- 루틴은 「무엇을(항목)」 의 순서만 정하고, 「어디를(단원)」 은 진도가
  따라온다. 회독 분기(round) · 예습 숙제(home_next = 다음 단원) ·
  항목별 주의사항(대괄호 메모)까지 루틴이 안다.
- 교재 루틴이 없으면 **영역 루틴**(문법·영작)이 받친다. 커버리지는 재원
  전원 (단어책은 루틴 없음 — 단어시험 체계가 담당. 저절로 기본1/2·입문2 는
  의도적 제외).

## 3. 교재별 루틴 요약 (확정본 — 원본은 [[루틴-받아적기]] · `drafts.json`)

| 교재 | 뼈대 |
|---|---|
| 일관성 영문법 · 문장훈련 | 한 수업에 9단계 순서대로: 의미덩어리 구두테스트(또는 백지) → 클카 4종(단어 3초훈련 · 직독직해 입해석 · 낭독 · 녹음) + 스크램블 4000+ → 구두테스트 → SVOCM 표시 → 채점 후 틀린 문장 해석 검사. 복습 숙제: 낭독/녹음·암기 100% · 스크램블 6000+ |
| 저절로리딩 브릿지1 | 1회독 예습(쇼츠 빈칸 · Step2까지 · 클카 암기 100%) → 등원은 회독에 따라: 1회독 채점·클카(3초훈련·낭독·녹음·암기)·Step3 기호·Step4 한글뜻 / 2회독 채점·클카(낭독·녹음·스크램블 기록경신)·Step5 영작 / 3회독 클카·테스트북. **2·3회독 예습은 현재 비어 있음 — 원장님 확인 대기** |
| 브릿지2 불규칙동사 | 회독마다 예습(1회독: 쇼츠 빈칸 · 불규칙동사 녹음 3번 카톡인증 · Step1까지 · 스크램블 4000+ / 2회독 6000+ / 3회독 8000+) → 등원(1회독 채점·클카·Step3·4 / 2회독 채점·클카·Step5 영작 / 3회독 클카·테스트북 영작) |
| 수능딥독 1·2·3 | 예습(단어·문제·매칭 3000) → 등원(워크북 채점 · 클카 3종 · 세모별표 검사) → 복습(워크북 · 끊어읽기 · 해석 · 스크램블 4000+) |
| 자이스토리 독해 | 예습 1항목 + 체크리스트 5줄 (시간 재기 · 끊어읽기 · 근거 표시 · 단어 · 형광펜) → 등원: 채점 · 틀린 문제 클카 3단계 · 해설 확인 후 구두테스트 |
| 저절로 첫모의고사 | 예습(쇼츠 빈칸 · 단어·지문) + 복습(클카 6000+ · 한줄해석 · 구조 정리·문제풀기) → 등원(클카 4000+ · 박스그래머 구두테스트) |
| 모의고사 12권 | 1회독: 직독직해·낭독·녹음·분석지·구두테스트 / N회독: 자유 1회독. 숙제: 논리구조 워크북 · 날짜기록 · 변형문제+근거 |
| 첫단추 독해유형편 | 숙제(해결전략 정독·문답노트 / 문제는 시간 재고) → 등원(문답노트 구두테스트 · 채점 · 오답풀이 구두테스트) |
| 빈순삽함 기본 이론편 | 숙제(정독·형광펜·요약정리 · 문제+질문 표시) → 등원(요약정리 구두테스트) |
| 영역: 문법 | 등원 = 개념정리(정독·형광펜·문답노트) → 구두테스트 → 문제풀기(오답노트) → 단원평가 대비 복습 / 숙제 = 같은 흐름에서 구두테스트 대신 셀프테스트 3회 녹음 인증(집). **자리 고정은 구두테스트(등원)·셀프녹음(집)뿐.** 인강·클카 문법훈련은 루틴 밖 — 부족한 학생만 수동 배정 (8단계 순차·예습1~4/복습5~8은 8/14 확정의 개념 정리) |
| 영역: 영작 (9권 일괄) | 예습: 설명 읽고 풀기 → 등원: 채점 · 세모별표 검사 |

- 학생별로 다른 값(독해 복습 반복 횟수 · 스크램블 개인 기준 · 오답노트
  개수 · 단어시험 방식)은 루틴이 아니라 **학생 축**으로 두기로 했다. 다만
  지금 앱의 학생 설정은 단어시험 방식·통과선 정도이고, 회독별 스크램블
  기본 기준(4000→6000→8000)은 루틴의 대괄호 메모가 갖고 있으며, 반복
  횟수는 「⟳ 루틴 다음」 을 안 누르는 것으로 표현한다.

## 4. 검사 판정의 자동화 (클래스카드)

- 크롬 확장이 15분마다 플래너·진도를 읽어 앱으로 보낸다.
- 그날 마감 세트 전부 완료 ○ · 일부 △(%) · 전무 ✕ — **검사 칸에 미리
  채운다** (「자동」 태그, 저장해야 확정 — 원장님 2026-08-20 「자동화
  시급해」 로 채움을 켬). 미달은 「안 함」 이 아니라 「day3 매칭 3000점
  미달」 처럼 구체적으로.
- **검사 메모 병기도 켜져 있다** — 원장님이 자동 판정을 그대로 두고 저장한
  항목만, 미달 상세(「Day 3 매칭 3000점 미달」)가 check_note 로 학생
  화면(💬 선생님)·데일리리포트에 병기된다.
- **그림자 기록은 계속**: 저장 때마다 자동 vs 실제 판정을 나란히 적어(0132)
  대시보드에 지난 30일 일치율이 뜨고, 9월 중순(9-17경) 평가한다. 틀린
  「미달」 이 학부모께 나가는 것이 제일 나쁘기 때문이다. 검증 뒤로 미룬
  것은 내신 「시험범위 1회독」 규칙 · B/B'(세트 지도) · 감시② 할일 자동
  생성 쪽이다. → [[클래스카드-연동-설계]]
