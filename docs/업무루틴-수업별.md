# 업무루틴 — 수업별 (학생 한 명 판)

> [[업무루틴-지도]] · 위 층위: [[업무루틴-일별]] · 다음: [[업무루틴-재원생별]]
> 루틴 원본(구술 그대로): [[루틴-받아적기]] · 확정 근거: [[기본학습-정리-2026-08-14]]

수업의 단위는 「학생 한 명 판」 이다. 학생이 오는 순서대로 판을 열고,
저장하면 완료로 내려간다. 판의 순서는 **수업 흐름 그대로**다 (0118 재정비).

## 1. 판의 처리 순서

```
① 출결 (정시/지각/결석/보강 — 한 탭)
② 낸 것 · 말할 것 (제출물 · 전달사항)
③ 테스트 — 단어 · 문법: 틀린 개수만 넣으면 통과/미통과 자동
   (통과선: 학생 것 → 없으면 설정 기본. 통과 여부는 저장 안 함 — 매번 계산)
④ 단원평가 — 단원명 + 점수 (적은 것만 성적으로 흘러간다)
⑤ 숙제 검사 ○△✕
   · 1차 판단은 자동 채움: 클카 판정(그림자 검증 중) + 학생 제출물
     + 「다 했어요 ○로 채우기」 — 「자동」 태그, 저장해야 확정
   · 안 해온 숙제 처분: 「오늘수업으로」 / 「숙제 다시」 (항목별 기본 처분)
⑥ 등원 학습 — 순서 목록 (↑↓ · ✕ · 「다음수업」 · 「숙제로」)
   · 소화량 게이지: 학생별 8주 타이머 실적으로 넘치면 「숙제로 돌리기」 제안
⑦ 진도 — 끝낸 단원 체크 (회독별로 쌓인다), 진도 메모
⑧ 다음 — 「⟳ 루틴 다음」: 그 학생 차례의 등원 항목·숙제·범위가 자동으로
   채워진다. 다음 수업 미리 계획(plan_next)도 여기서
⑨ 집중도 · 이해도 별점 + 키워드 코멘트 (고른 것만 리포트에 나간다)
⑩ 공지 → 늦귀가 → 하원 안내 → 재시험 · 보강
```

- **임시저장** — 다 저장하되 완료로 안 넘긴다 (수업 중 끊겨도 안 날아감).
- 저장 시 숙제 목록이 바뀌면 학생에게 푸시 (다음 정각 배치).

## 2. 루틴이 채우는 것 — 「⟳ 다음」 의 뒤

- **루틴은 교재별**이다 (학생별 아님). 학생의 현재 단계는
  `student_textbooks.routine_step` 이 기억한다.
- 루틴은 「무엇을(항목)」 의 순서만 정하고, 「어디를(단원)」 은 진도가
  따라온다. 회독 분기(round) · 예습 숙제(home_next = 다음 단원) ·
  항목별 주의사항(대괄호 메모)까지 루틴이 안다.
- 교재 루틴이 없으면 **영역 루틴**(문법·영작)이 받친다. 커버리지는 재원
  전원 (단어책 · 저절로 기본1/2 · 입문2 는 의도적 제외).

## 3. 교재별 루틴 요약 (확정본 — 원본은 [[루틴-받아적기]])

| 교재 | 뼈대 |
|---|---|
| 일관성 영문법 · 문장훈련 | 한 수업에 9단계 순서대로 (구두테스트 → 클카 3종 → 스크램블 4000+ → SVOCM → 오답 해석검사). 복습 숙제: 낭독/녹음·암기 100% · 스크램블 6000+ |
| 저절로리딩 브릿지1 | 예습(쇼츠·Step2까지·클카) → 등원은 **회독에 따라** 다름 (1회독 Step3·4 / 2회독 Step5 영작 / 3회독 테스트북) |
| 브릿지2 불규칙동사 | 회독마다 예습(스크램블 4000→6000→8000) + 등원 채점·클카·영작 |
| 수능딥독 1·2·3 | 예습(단어·문제·매칭 3000) → 등원(워크북 채점·클카 3종·세모별표 검사) → 복습(워크북·끊어읽기·해석·스크램블 4000+) |
| 자이스토리 독해 | 예습 1항목 + 체크리스트 5줄 (시간 재기·끊어읽기·근거 표시·단어·형광펜) → 등원: 채점 · 틀린 문제 클카 3단계 · 해설 확인 후 구두테스트 |
| 저절로 첫모의고사 | 예습(단어·지문) + 복습(클카 6000+ · 한줄해석 · 구조 정리) → 등원(클카 4000+ · 박스그래머 구두테스트) |
| 모의고사 12권 | 1회독: 직독직해·낭독·녹음·분석지·구두테스트 / N회독: 자유 1회독. 숙제: 논리구조 워크북 · 날짜기록 · 변형문제+근거 |
| 첫단추 독해유형편 | 숙제(해결전략 정독·문답노트 / 문제는 시간 재고) → 등원(문답노트 구두테스트 · 채점 · 오답풀이 구두테스트) |
| 빈순삽함 기본 이론편 | 숙제(정독·형광펜·요약정리 · 문제+질문 표시) → 등원(요약정리 구두테스트) |
| 영역: 문법 (8단계) | 정독·형광펜 → 문답노트 → 셀프테스트 3회 녹음(집) → **구두테스트(등원)** → 본교재 → 워크북 → (선택) 클카 문법훈련 → 단원평가 대비 복습. 예습=1~4, 복습=5~8 |
| 영역: 영작 (9권 일괄) | 예습: 설명 읽고 풀기 → 등원: 채점 · 세모별표 검사 |

- 학생별로 다른 것은 루틴이 아니라 **학생 설정**이다: 독해 복습(클카 묶음)
  반복 횟수 · 스크램블 점수 기준 · 오답노트 개수 · 단어시험 방식.

## 4. 검사 판정의 자동화 (클래스카드)

- 크롬 확장이 15분마다 플래너·진도를 읽어 앱으로 보낸다.
- 그날 마감 세트 전부 완료 ○ · 일부 △(%) · 전무 ✕ — 지금은 **그림자 모드**
  (태그로만 보여주고 검사는 안 채움, 자동 vs 실제 판정 일치율을 30일 쌓아
  9월 중순 평가 후 켤지 결정). 틀린 「미달」 이 학부모께 나가는 것이 제일
  나쁘기 때문이다. → [[클래스카드-연동-설계]]
