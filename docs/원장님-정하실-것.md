## 퇴원한 아이 정보 지우기 — 넷 (2026-09-03 · **쉬운 말로 다시 씁니다**)

### ④ 그 「이름 가리기」를 **언제 돌릴까요?**

| ㉡ | 넷을 다 지워야 날짜를 적습니다 — 그러면 **지금은 아무도 못 적습니다** |

| | |
