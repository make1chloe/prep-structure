## 새로 여쭐 것 둘 (2026-09-02)

### ① 휴강 **사유**를 아이·학부모가 봐도 되나요?

휴강 **날짜**는 아이·학부모 달력에 보입니다 — 학원이 안 여는 날을 모르면 그날 옵니다.
그런데 같은 줄에 **사유**가 붙어 있습니다(「추석 연휴」는 괜찮지만 「원장 개인사정」은 다릅니다).

접근 규칙은 **줄은 가려도 칸은 못 가립니다.** 그래서 둘 중 하나입니다.

| | |
|---|---|
| **가린다** (지금 이렇게 해 뒀습니다) | 아이·학부모 화면에 **날짜만** 나갑니다. 사유는 원장님만 |
| 보여준다 | 사유를 적으실 때 **학부모가 읽는다는 걸 아셔야** 합니다 |

지금은 **가리는 쪽**으로 두고 검사를 달았습니다 — 나중에 누가 사유를 내려보내면 그 자리에서 걸립니다.
**보여주는 쪽이 나으면 말씀해 주세요.**

### ~~② 지난 시간 낸 숙제가 오늘 검사 자리에 서는 규칙~~ — ✅ **「나」로 정해 주셨습니다**

| 남음 | 같은 숙제가 **두세 번 서는 것**을 묶어야 합니다(실측 7묶음) |

### ③ 발송 화면의 「읽음」을 **며칠치** 보여드릴까요?

예전에는 **전 학생 최근 200줄**로 잘라서 보여드렸습니다. 그러면 자취가 쌓인 뒤
「안 읽은 집만 보기」가 그 200줄 안에서만 걸러 **「안 읽은 줄이 없습니다」가 거짓이 됩니다.**

지금은 **「오늘 명단 + 최근 14일」**로 좁혀 놓았습니다.

| | |
|---|---|
| **14일** (지금) | 학부모가 며칠 뒤에 여는 일이 있어 넉넉히 잡았습니다 |
| 7일 | 화면이 가벼워집니다. 대신 지난주에 보낸 것은 안 보입니다 |
| 30일 | 한 달치를 다 봅니다. 줄이 많아집니다 |

⚠️ **14일은 제가 정한 값입니다** — 계획에 날 수가 안 적혀 있습니다.
바꾸고 싶으시면 말씀해 주세요. 창 밖에 남은 것은 화면이 **「창 밖에 N줄 더」**로 밝힙니다.

## 새로 여쭐 것 넷 — 파기 (2026-09-03)

「파기한 날」 칸을 만들면서 **답이 없으면 못 지나가는 것**이 나왔습니다.

### ④ 퇴원 파기를 **누가 어디서** 부르나요?

지금 앱에 **부르는 자리가 0곳**입니다 — 파기하는 손은 다 지어 놨는데 누르는 데가 없습니다.

| | |
|---|---|
| ㉠ | 재원생 화면에 **「파기」 단추**를 두고 원장님이 누르신다 |
| ㉡ | 퇴원(중단) 처리하고 **N일 뒤 크론이 저절로** 돈다 — 그러면 **N은 며칠**인가요? |

### ⑤ 「파기한 날」이 **무엇까지** 끝난 날인가요?

지금 코드가 증명할 수 있는 것은 **v2 안에서 이름·전화·글을 가린 것**까지입니다.
**학부모 로그인 · 숙제 사진 파일 · 옛 앱 한 벌**은 손으로 따로 하는 자리라 이 날짜가 못 덮습니다.

| | |
|---|---|
| **㉠** (지금 이렇게) | **v2 가린 날만** 기록하고 손일은 따로 적습니다. 칸 이름도 `v2_masked_at` 으로 지어 **과하게 말하지 않게** 했습니다 |
| ㉡ | 셋 다 끝나야 날짜를 찍는다 — 그러면 **지금은 아무도 못 찍습니다** |

### ⑥ 할 일 제목에 든 아이 이름 — 퇴원하면 어떻게 할까요?

실측으로 **8줄**에 이름이 그대로 있습니다
(「공○○ 관계사 추가프린트」·「이○○ — 결제선생 등록」·「양○○ 현금영수증 8/24」 …).

| | |
|---|---|
| ㉠ | 이름만 가린다 (「공○○ 관계사 추가프린트」) |
| ㉡ | 그 할 일 줄을 통째로 내린다 |
| ㉢ | 그대로 둔다 — 원장님 일정 기록이니까 |

⚠️ 결제·현금영수증 줄은 **회계 기록**으로 남겨야 하는지도 같이 봐 주세요.
지금은 이 이름들이 남아 있으면 **파기 도장을 안 찍고 「이름이 남았다」고 알립니다.**

### ⑦ 휴원 중인 형제가 있으면 학부모 계정을 안 지우는 게 맞나요?

지금은 **휴원을 재원으로 보고 안 지웁니다**(되돌릴 수 있는 쪽). 코드에 「확인 안 됨」으로 적혀 있습니다.

## 등원·발송 — 짓다가 남긴 미결 (문서에 안 적혀 있었습니다)

### ⑨ ⚠️ **학원 아이피가 비어 있어 지금은 아무도 등원을 못 찍습니다**

실측: `v2.integration('arrival').config.ips = []`.
아이가 학원에서 눌러도 **「학원에서 접속한 게 아닙니다」로 막힙니다.**

→ **원장님이 학원에서 한 번 눌러 주시면** 그 자리의 아이피가 담깁니다.
⚠️ 그리고 계획서가 미확인으로 남긴 자리가 여기 걸립니다 —
**학원 회선이 IPv6 면** 앞 4덩어리 비교가 실제 회선에 맞는지 **아직 아무도 모릅니다.**
옛 앱도 같은 규칙이었는데 그 목록이 **0줄**이라 한 번도 켜진 적이 없습니다.
**리허설 때 학원에서 실제로 눌러 봐야** 압니다.

### ⑩ **하원**(집에 간 시각)을 어디에 적을까요?

옛 앱에는 `leave_at` 이 네 번째 칸으로 있었는데, 새 등원은 **세 걸음**(핸드폰·출석·숙제)이라 자리가 없습니다.

| | |
|---|---|
| ㉠ | 등원에 네 번째 걸음으로 되돌린다 |
| ㉡ | 늦귀가에만 적는다 (지금 `late_stay.left_at` 이 그 자리입니다) |
| ㉢ | 안 적는다 |

⚠️ 확정-⑭가 「**예상 귀가는 약속이 된다** — 실제 하원을 찍어 차이를 같이 남긴다」이므로
늦귀가에는 이미 자리가 있습니다. 물음은 **평소 하원도 찍을지**입니다.

### ⑪ 아이가 등원을 찍으면 **어머니께 알림**이 가야 하나요?

옛 앱은 보냈습니다. 새 계획에는 그 말이 없어 **안 만들었습니다.**
보내는 쪽이면 하루 23통이 더 나갑니다.

### ⑫ 같은 날 반이 둘일 때(정규+특강) 어느 반에 찍나요 — 확인만

지금은 **시작 시각이 이른 반**에 찍고 나머지를 화면에 밝힙니다. 이대로 두어도 될지만 봐 주세요.

### ⑬ 알림 열쇠(VAPID)가 **옛 앱 것과 같은 것**이 맞나요?

DB(`v2.integration('push')`)에 들어 있습니다. 다만 **옛 앱이 쓰던 그 열쇠인지는 확인 못 했습니다** —
다르면 전환 첫날 **이미 알림을 켠 기기 3대가 조용히 끊깁니다**(원장 2 · 학생 1).

### ⑭ 숙제 갯수 조절 — 「세 번까지 기다릴까요」는 아직 답이 없습니다

2026-09-02 에 「**반복 버튼 누르면 그대로, 루틴 누르면 루틴대로 다시 부여**」라고 답해 주셨는데,
