# 원장님이 정하실 것

> 짓다가 「이건 원장님만 아신다」로 남은 것. **지어내지 않고 여기 모았다**(대전제 0).

| | 답 |
|---|---|
| 아이가 찍은 진도가 확인 전에도 커서를 움직여도 되나 | **그대로 둔다** (2026-09-02) |
| 그래머인사이드 GRAMMAR BASICS 3줄이 엑셀에 없다 | **엑셀을 고칠 게 아니다** — DB 에서 내려받으면 따라온다 |

## 아직 답이 필요한 것 — **원장님이 화면에서 보실 모습**으로 씁니다

### 3. 표가 길면 어떻게 내려갈까요? (PC·아이패드에서만)

**지금 이렇게 해 뒀습니다**

```
┌────────────────────────────┐
│ 이름 │ 반 │ 교재 │ 진도  │ ← 이 줄이 **안 움직이고 붙어 있음**
├────────────────────────────┤
│ 김서은 │ … │ … │ …      │ ▲
│ 구도은 │ … │ … │ …      │ │ 표 **안에서만** 내려감
│ 노주하 │ … │ … │ …      │ ▼
└────────────────────────────┘
   ↑ 표 밑의 다른 카드는 그 자리에 그대로
```

**바꾸면 이렇게 됩니다**

```
페이지가 통째로 내려감 → 열 이름(이름·반·교재)이 위로 사라짐
```

**여쭙는 것: 열 이름이 붙어 있는 게 나은가요, 페이지째 내려가는 게 나은가요?**
(폰은 어느 쪽이든 지금 그대로입니다)

---

### 4. 칸이 많은 표를 폰에서 어떻게 볼까요?

**지금 이렇게 해 뒀습니다** — 옆으로 밀어서 봅니다

```
│ 김서은 │ 월수 │ 3800제 │ 12/47 │ →  (옆으로 밀면 더 있음)
```

**안 그러면 이렇게 됩니다** — 짜부라져서 세로로 쌓입니다

```
│ 김 │ 월 │ 38 │ 12 │
│ 서 │ 수 │ 00 │ /4 │
│ 은 │    │ 제 │ 7  │
```

**이건 그냥 확인만 받는 겁니다.** 옆으로 미는 게 맞다고 봅니다.

---

### 5. 단원 이름이 겹치는 교재 4권 — 중단원을 같이 띄울까요?

**어법끝스타트**는 「Points to Remember」가 **8곳에 똑같이** 있습니다.
그래서 카드만 보면 어느 UNIT 이 나가는지 모릅니다.

| 지금 (고침) | 고치기 전 |
|---|---|
| PART 2 › **UNIT 01 동사 밑줄** › Points to Remember | PART 2 › Points to Remember |
| PART 2 › **UNIT 02 시제 밑줄** › Points to Remember | PART 2 › Points to Remember ← **똑같음** |

**여쭙는 것: 이름이 길어져도 UNIT 이 보이는 게 나은가요?**
(겹치는 4권에서만 길어집니다. 나머지 교재는 지금과 똑같습니다)

---

### 6. 수업 중에 「오늘 20분 늦었어」를 그 자리에서 찍고 싶으신가요?

**지금**: 지각은 **달력**에서 미리 고릅니다 (「다음 주 화요일 20분 늦어요」).
**더하면**: 오늘 화면 명단 옆에 「지각 ▾ 10·20·30·60분」이 하나 더 생깁니다.

**여쭙는 것: 오늘 화면에도 두는 게 나은가요, 달력만으로 충분한가요?**

---

### 7. 늦귀가 시간 단추를 몇 개로 할까요?

지금 두 자리의 단추가 다릅니다.

| 어디 | 단추 |
|---|---|
| **늦귀가** (남아서 하고 감) | +20분 · +40분 · +1시간 |
| **지각** (늦게 옴) | 10분 · 20분 · 30분 · 1시간 |

**여쭙는 것: 그냥 두어도 되나요, 같게 맞출까요?**

---

### 8. 숙제 갯수를 줄였을 때 **다음에도 그렇게** 낼까요?

**예:** 김서은 3800제를 「3개 → 2개」로 줄였습니다.

| 그날만 | 다음에도 |
|---|---|
| 다음 회차엔 다시 3개 | 계속 2개 |
| 매번 줄여야 함 | 한 번만 줄이면 됨. 늘리려면 다시 고침 |

계획에는 「**같은 조절을 세 번 하면 앱이 먼저 묻는다**」로 적혀 있습니다.
**여쭙는 것: 세 번까지 기다릴까요, 한 번 줄이면 바로 담을까요?**

---

### 9. 워크북 줄에 소단원 이름이 붙어 있는데 — 괜찮은가요?

원장님이 「워크북은 전체를 시키니까 단원 구분명이 없다」고 하셨는데,
**옛 앱 DB 에는 이름이 있었습니다** (「워크북 01 현재진행형」 — 11권 전부).
그래서 안 지웠습니다.

- **화면에는** 이름이 보입니다 (「Unit 01 시제 › 01 현재진행형 · 워크북」)
- **나갈 때는** 대단원 통째로 나갑니다 (원장님 방식 그대로)

**여쭙는 것: 화면에 이름이 보이는 게 거슬리시나요?**

## 아직 못 하는 것 — 아셔야 할 것

| | 왜 |
|---|---|
| **늦귀가 「보내기」** | 실제로 쏘는 손을 짓는 중 |
| **오늘 화면이 0.7초** (목표 0.5초) | 줄이는 중 |
| **영역 메모** (단어·독해·문법·영작 한 줄씩) | 담을 칸이 DB 에 없다. 교재마다의 메모는 있다 |
| **루틴 「더하기·차례 바꾸기」** | 빼기만 된다 |
| **카드 순서 바꾸기** | 표는 있는데 쓰는 자리가 없다 |
| **클래스카드 「목표 미달」** | 확장이 점수를 다 보내는데 판정하는 자리가 없다 |
| **AI 브리핑** (키워드 → 살 붙이기) | 부르는 자리가 아직 없다 |
