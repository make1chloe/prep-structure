# 아직 확인 못 한 것

제가 **직접 돌려보지 못한** 것만 모아둡니다. "될 겁니다" 로는 아무것도 확인되지
않습니다. 실제로 한 번 되면 여기서 지웁니다.

지난번에 이 목록에 있던 것(0044 저장소 권한)에서 정확히 문제가 났습니다.
그래서 지우는 기준을 낮추지 않습니다 — **원장님이 실제로 한 번 성공해야** 지웁니다.

---

## 1. 숙제 파일 보관함 (사진 · 녹음)

**왜 확인이 안 되나** — 제 상자의 Postgres 에는 Supabase 의 `storage` 스키마가
없습니다. 표와 함수는 진짜 Postgres 에 세 번씩 돌려보지만, 저장소 권한만은
그 안에 없어서 넘어갑니다.

**한 번 해보실 것**
1. 설정 → Supabase SQL → 「숙제 파일 점검」 — 올리기·보기·지우기를 실제로 해봅니다
2. 학생 화면에서 **사진 한 장**, **녹음 하나** 를 실제로 내보기

**안 되면 이렇게 뜹니다** — "파일을 올릴 권한이 없어요… 0047 을 실행해주세요"

---

## 2. 나이스(NEIS) 학사일정

**왜 확인이 안 되나** — 제 작업 환경의 망 정책이 `open.neis.go.kr` 을 막고
있습니다 (`CONNECT tunnel failed, 403`). 원장님 사이트에서는 막힘이 없습니다.

**확인한 것** (인터넷 없이 되는 것)
- 정상 응답 읽기 · 빈 응답(INFO-200) · 키 오류(ERROR-290)
- 시험 기간 묶기 (사흘짜리 고사가 기간 하나로)
- 주소 만들기 · 날짜 변환 · 같은 것 두 번 안 넣기

**확인 못 한 것** — 나이스가 실제로 주는 응답의 모양. 문서 기준으로 맞췄습니다.

**한 번 해보실 것**
1. 인증키를 앱에 넣기 (받으셨습니다)
2. 학교 **하나만** 넣고 한 달치 받아보기

**안 되면 이렇게 뜹니다**
- 「나이스 인증키가 맞지 않아요」 → 키 문제
- 「그 기간에는 학사일정이 없어요」 → 정상 (오류 아님)
- **「모르는 모양의 답이 왔어요」 → 제 예상이 틀린 것입니다. 알려주세요**

---

## 3. 알림톡 (문자는 확인 끝)

**문자는 2026-08-03 에 본인 번호로 실제 발송 확인했습니다.** ✅
거기까지 오는 데 걸린 것들 — API Key 칸에 로그인 이메일 · 솔라피 IP 접근 제한 ·
우리가 붙인 잘못된 파라미터(limit) · 등록 번호 목록을 잘못 읽은 것 — 은
모두 화면에서 알아볼 수 있게 고쳤습니다.

**알림톡은 아직입니다.** 배관은 다 있는데(템플릿 코드 · 변수 연결 · 발송 경로)
**카카오에서 승인받은 템플릿이 있어야** 실제로 나가는지 볼 수 있습니다.

**한 번 해보실 것**
1. 카카오에서 템플릿 승인받기 (반복되는 것만 — 데일리리포트 · 숙제 · 하원 · 월간)
2. 설정 → 문자 문구 → 그 문구 → **알림톡 템플릿 코드** 붙이기
3. 위쪽 **「지금 무엇이 알림톡으로 나가나」** 판에서 초록불 확인
4. 발송 → **테스트** 탭에서 본인 번호로 한 통

**확인할 것** — 알림톡으로 나가는지, 그리고 **막힌 번호에 문자로 대신 나가는지**
(disableSms: false 로 보내고 있지만 실제로 대체되는 것은 못 봤습니다)

## 4. 구글 캘린더 구독 (.ics)

**왜 확인이 안 되나** — 구글이 원장님 앱 주소를 실제로 읽어가는 것은
제 상자에서 못 봅니다. DB 쪽은 진짜 Postgres 로 확인했습니다 —
맞는 열쇠는 일정·시험·휴강이 나오고, **틀린 열쇠는 0행**, 학생 계정(anon)은
열쇠 표를 직접 못 읽습니다. 못 본 것은 **구글이 그 파일을 제대로 읽나** 입니다.

**한 번 해보실 것**
1. 할일·일정 → 달력 → 「구글 캘린더에 넣기」 → 주소 만들기
2. 그 주소를 브라우저 주소창에 그냥 붙여넣어 보기 — 글자가 주르륵 나오면 정상
   (`BEGIN:VCALENDAR` 로 시작합니다)
3. 컴퓨터에서 calendar.google.com → 다른 캘린더 ＋ → URL로 만들기

**안 되면**
- 「달력을 내줄 수 없습니다」 → 0078 이 안 들어갔거나 주소가 틀렸습니다
- 구글이 「캘린더를 가져올 수 없습니다」 → 주소 오타이거나 앱이 배포 중입니다
- **날짜가 하루씩 밀려 보이면 알려주세요** — 하루 종일 일정으로 넣고 있어서
  안 밀려야 정상입니다

## 5. 홈 화면 아이콘 (로고 올리기)

**왜 확인이 안 되나** — 폰에서 「홈 화면에 추가」 를 해보는 것은 제 상자에서
못 합니다. 만드는 쪽(크기 맞추기·여백 주기)은 브라우저에서 돌고, 내어주는
쪽은 `/api/icon/…` 입니다.

**한 번 해보실 것**
1. 설정 → 화면 → **홈 화면 아이콘** 에 로고 파일 올리기
2. 그 자리 미리보기에서 **동그랗게 잘릴 때** 판이 로고를 안 자르는지 보기
3. 폰에서 「홈 화면에 추가」 — **이미 추가해둔 것은 지우고 다시** 해야 합니다

**안 되면**
- 「0080 SQL 을 먼저 실행해주세요」 → SQL 이 안 들어갔습니다
- 아이콘이 **검게** 나오면 → 투명 처리가 샌 것입니다 (흰 바탕으로 굽고 있어서
  안 그래야 정상입니다). 알려주세요
- 로고가 잘려 보이면 → 「동그랗게 잘릴 때」 판의 여백을 더 줘야 합니다

## 확인이 끝난 것 (참고)

- 표·함수 SQL — 진짜 Postgres 에 세 번씩 실행 (`scripts/check-sql.sh`)
- 학생 계정에 남의 것이 보이는지 — 진짜 Postgres 에 학생 두 명을 앉혀서
  (`scripts/check-leak.sh`)
- 학생이 열 수 있는 화면 (`scripts/check-routes.mjs`)
- 월말 리포트 · 경고 · 대기줄 · 수강료 계산 — 계산은 인터넷이 필요 없습니다
