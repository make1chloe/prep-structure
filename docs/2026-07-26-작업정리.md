### 무엇을 고쳤나

**① 숙제 검사 ○ △ ✕ 를 바로 누른다**
예전에는 칩 하나를 돌려서 `완료 → 미흡 → 미제출 → 없음` 이라 **미제출은 3번** 눌러야 했습니다.
이제 세 버튼이 나란히 있어 뭘 찍든 1탭입니다.

**② 채점 피드백 칸이 생겼습니다** (0024)
`△ 미흡` 이나 `✕ 미제출` 을 찍으면 **그 숙제 바로 아래 메모칸이 자동으로 열립니다.**
"3번 문제 대명사 지칭 틀림" 처럼 적으면 학부모 문자에 이렇게 나갑니다.

```
· 숙제: 단어 완료 / 독해 미흡 / 문법 완료
   └ 독해: 3번 문제 대명사 지칭 틀림
```

전에는 리포트 전체 '공지' 한 칸에 몰아 써야 했습니다.

**③ ⟳ 지난번과 같게** — 다음 숙제 배정이 전체 탭의 **49%** 를 먹고 있었습니다.
매번 항목·교재·단원을 처음부터 다시 골랐기 때문입니다.
이제 한 번 누르면 **지난번 항목과 교재를 그대로 가져오고 단원만 다음 것으로** 옮겨줍니다.

**④ 반 전체에 같은 숙제** — 한 명을 다 만든 뒤 한 번 누르면 나머지에게 복사됩니다.
**이미 숙제가 배정된 학생은 건드리지 않습니다.**

**⑤ 테스트 점수는 '틀린 개수'로 입력**
채점할 때 실제로 세는 건 틀린 개수입니다 (노션에서도 `-단어T` 로 적으셨고요).
전체 개수는 **지난번 값이 미리 채워져** 있어서, 틀린 개수만 치면 맞은 개수가 계산됩니다.

**⑥ 보강 학생 줄에 원 결석일** — `보강 · 9/2 결석분` 이 붙습니다.
그날 뭘 못 했는지 알아야 무엇을 채울지 정하니까요.

**⑦ 오늘 수업 맨 위에 "수업 전에 볼 것"**
학부모 댓글·결석 요청이 대시보드에만 있어서 화면을 왔다갔다 해야 했습니다.
이제 **오늘 오는 학생 것만** 추려서 오늘 수업 맨 위에 뜹니다.

## ✅ 이번에 만든 것

### 회차 알림을 3개월 누적으로 바꿈
달마다 따로 판정하지 않습니다. 8월 7회 + 9월 9회면 서로 상쇄되므로

> 8월 7회(-1) · 9월 9회(+1) → **9월까지 합치면 기준과 정확히 맞습니다.
> 보강도 휴강도 하지 말고 9월까지 그대로 수업하면 됩니다.**

상쇄되는 달은 초록 `회차 맞음` 태그가 붙고 휴강 지정 버튼도 안 뜹니다.
**3개월을 다 합쳐도 남을 때만** "서비스로 할지 휴강할지" 물어봅니다.

### 금요일 = 보강만 하는 날
`설정 → 보강만 하는 요일` 에서 관리 (기본값 금).
고른 요일은 **수강료 회차와 스케줄 알림에서 빠집니다.** 보강 잡는 건 그대로.

### 공휴일 · 대체공휴일 · 낀 날 알림
**자동으로 쉬지 않습니다.** 수업이 잡힌 날만 골라서 알리고, 판단은 원장이 합니다.

- 공휴일 — "5/5 어린이날인데 수업일입니다"
- 대체공휴일 — "3/1이 일요일이라 3/2로 밀렸습니다. 학교마다 다를 수 있으니 확인해주세요"
- 낀 날 — "앞뒤가 공휴일·주말입니다"

알림에서 바로 **전체 휴강 / 반별 휴강** 지정 가능.

### 엑셀 · CSV 이관 두 가지 추가
`/import` 에 탭이 늘었습니다.

- **일정 · 할일** — 노션 학사일정DB, 또는 직접 만든 엑셀
  (`제목 / 종류 / 분류 / 날짜 / 끝날 / 메모`). 종류가 없으면 제목으로 일정·할일을 나눔
- **결석 · 보강** — 노션 보강문자DB

### 2026 시험 일정 이관
노션에는 기간("신송중 2회고사")과 영어시험일("신송중 영어시험")이 **따로** 있었는데
학교로 짝지어 한 줄로 합쳤습니다. 21건.

### 숙제 · 리포트 댓글

- 대시보드 특이사항에도 목록. 선생님이 열면 자동 읽음 처리
- 학생·학부모는 **자기 것만** 보고 씁니다. 역할은 서버에서 정해서 위조 불가
