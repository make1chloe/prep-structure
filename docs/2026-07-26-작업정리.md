## 🖐 수업 중 동선

`scripts/simulate-workflow.mjs` 로 **하루 일이 어떤 순서로 흘러가는지**를 따라갔습니다.
수업 전 → 수업 중(학생 한 명씩) → 하원 → 발송 → 다음 수업 준비.
학생은 **전원 개별진도** (교재도 단원도 다 다름), 반 2개 + 보강 학생이 섞인 상태.

### 고친 것

**① 숙제 검사 ○ △ ✕ 를 바로 누른다**
예전에는 칩 하나를 돌려서 `완료 → 미흡 → 미제출 → 없음` 이라 **미제출은 3번** 눌러야 했습니다.

**② 재시험 · 보강 날짜를 오늘 수업 화면에서 바로 잡는다**
검사하다 "그럼 목요일에 다시 보자" 가 되는데, 일정 화면으로 나갔다 와야 해서
수업 흐름이 끊겼습니다. 이제 학생 칸 안에서 날짜만 고르면 끝이고,
**미제출·미흡으로 찍은 항목 이름이 사유에 미리 적혀** 있습니다.
그날 오늘 수업 화면에 `보강 · 단어 재시험` 으로 뜹니다.

**③ ⟳ 지난번과 같게**
개별진도라 학생마다 교재·단원이 다른데 매번 처음부터 골랐습니다.
한 번 누르면 **그 학생의 지난번 교재를 그대로 가져오고 단원만 다음 것으로** 옮겨줍니다.

**④ 테스트 점수는 '틀린 개수'로 입력**
채점할 때 실제로 세는 건 틀린 개수입니다 (노션에서도 `-단어T`).
전체 개수는 **지난번 값이 미리 채워져** 있습니다.

**⑤ 보강 학생 줄에 사유·원 결석일** — `보강 · 단어 재시험`, `보강 · 9/2 결석분`

**⑥ 오늘 수업 맨 위에 "수업 전에 볼 것"**
학부모 댓글·결석 요청이 대시보드에만 있어 화면을 왔다갔다 했습니다.
이제 **오늘 오는 학생 것만** 추려서 뜹니다.

**⑦ 오늘 수업 맨 아래에 "발송하러 가기"** — 다 찍고 나서 메뉴를 다시 찾지 않게

### 안 만든 것 (하면 안 되는 것)

- **반 전체에 같은 숙제** — 만들었다가 **뺐습니다.** 전원 개별진도라 쓰면 안 됩니다
- **채점 결과 입력칸** — 만들었다가 **뺐습니다.** 채점 피드백은 수업 중에 말로 합니다

### 시뮬레이션이 착각했던 것 (확인해보니 이미 되고 있었음)

- 리포트 문구에 `▶ 다음 수업 숙제` 가 **이미 들어갑니다** → 학부모는 문자 한 통만 받습니다
- 보강 학생도 **결석 전에 낸 숙제가 그대로 검사 대상**으로 뜹니다

### 아직 남은 것

- **단원이 없는 교재** — 범위를 매번 손으로 칩니다. `⟳ 지난번과 같게` 도 안 먹습니다
- **시험 범위** — 내신 기간에 어디까지 낼지 판단할 근거가 화면에 없습니다 (내신 트랙, ROADMAP)

## ⚠️ 경고 · 반성문

**규칙** — 지각 / 숙제 미제출·미흡 / 단어시험 미통과 → 그날 **경고 1회**.
하루에 여러 개가 겹쳐도 1회입니다 (사유만 여러 개 적힘). 3회 쌓이면 반성문.

**경고는 저장하지 않습니다.** 지난 리포트에서 매번 셉니다.
그래야 리포트를 고쳤을 때 경고도 같이 맞습니다. 저장하는 건 **원장님이 내린 판단**뿐입니다.

- **이 날은 빼주기** — 사정이 있었으면 그날 경고를 없던 것으로
- **반성문 씀** — 정산하고 0부터 새로 셉니다
- **이번엔 넘어가기 (유예)** — 정산은 하되 **봐준 이력이 남습니다.**
  다음에 또 3회가 되면 `지난번 유예함` 표시가 함께 떠서 판단에 참고됩니다

**단어시험은 오답 10% 이내면 통과**입니다 (맞은 비율이 아니라 **틀린 비율**).
20개 중 2개까지는 통과, 3개부터 경고입니다.
기준은 `설정 → 경고 · 반성문 규칙` 에서 바꿉니다.

**유예해준 것도 문자에 나갑니다.** 봐줬다는 걸 알아야 다음에 조심하니까요.

```
유예한 날    학부모 ⚠ 경고 3회가 되어 반성문 대상이었지만, 이번에는 유예했습니다.
                    가정에서도 한 번 짚어주시면 좋겠습니다.
             학생   ⚠ 경고 3회 — 이번엔 반성문을 유예해줬어요. 다음엔 꼭 지켜주세요.

그 뒤 1회    학부모 ⚠ 경고 1/3회 — 지각
                    지난번에 한 번 유예해드렸습니다. 2회 더 쌓이면 반성문을 쓰게 됩니다.
```

문자에는 이렇게 나갑니다.

```
학부모 ⚠ 경고 3/3회 — 지각, 숙제 미제출 1건
       경고가 3회 쌓여 반성문 대상입니다. 지도 부탁드립니다.

학생   ⚠ 경고 3/3회 — 지각, 숙제 미제출 1건
       경고 3회 — 반성문을 써야 합니다.
```

## 🏠 오늘 마무리 (늦귀가과제)

이름은 **`오늘 마무리`** 로 했습니다. 하는 일 그대로이고 벌처럼 들리지 않습니다.
(`lib/reportText.js` 의 `STAY_LABEL` 한 줄만 고치면 이름이 전부 바뀝니다)

- 숙제를 **△·✕ 로 찍으면** 그 항목이 단원·범위까지 붙어서 **자동으로 제안**됩니다
- 남아서 하다가 결과를 셋 중 하나로 찍습니다

| | 문자에 어떻게 |
|---|---|
| **다 함** | 리포트에 `마치고 하원` |
| **숙제로** | 리포트에 `다 못 해 숙제로 넘김` + **숙제 문자에 함께** |
| **넘어가기** | 아무 문자에도 안 나감 (기록만) |

학생용 페이지에도 `오늘 마무리` 칸이 생겨서 학생이 직접 확인합니다.
오늘 수업 학생 줄에는 `마무리 2`, `경고 2`, `반성문` 배지가 뜹니다.

## 🔤 단어시험 방식 (학생 · 교재 · 회독마다)

단어시험은 학생마다 보는 방법이 다릅니다. 개수는 정하지 않고 **네 가지를 합쳐 100%** 로
배분합니다. 0인 건 안 보는 것입니다.

| | |
|---|---|
| 객관식 뜻 | 영단어 주고 뜻 고르기 |
| 주관식 뜻 | 영단어 주고 뜻 쓰기 |
| 객관식 영단어 | 뜻 주고 영단어 고르기 |
| 주관식 영단어 | 뜻 주고 영단어 쓰기 — **첫 글자 힌트 있음/없음** |

**교재를 시작할 때** 한 번 정하고, 다 끝내고 **한 번 더 돌릴 때(2회독)** 다시 정합니다.
회독마다 설정이 따로 남습니다 (2회독은 보통 더 어렵게 바꾸니까요).

오늘 수업에서 그 학생 단어책 진도 아래에 **라벨로 붙습니다.**

```
2회독 · 주뜻50 주단50(첫글자)
1회독 · 객뜻25 주뜻25 객단25 주단25(첫글자)
1회독 · 시험 방식 미설정          ← 아직 안 정한 교재는 노란 점선으로
```

0인 유형은 라벨에서 빠져서 짧습니다. 수업 중에 흘깃 보고 알아야 하니까요.
`⟳ 다음 회독으로` 를 누르면 회독이 올라가고 끝낸 단원이 비워집니다.

## 🕐 시간대 버그 — 날짜가 하루씩 밀리고 있었습니다

코드 곳곳에서 이렇게 쓰고 있었습니다.

```js
new Date("2026-09-24T00:00:00+09:00").getDate()
```

Vercel 서버는 **UTC** 로 돕니다. `+09:00` 로 읽으면 실제 시각은 `9/23 15:00Z` 가 되고,
`getDate()` 는 **서버(UTC) 기준**이라 **23** 을 돌려줍니다. 요일도 목 → 수로 밀립니다.

화면 날짜만 틀린 게 아니라 **공지 대상 학생이 잘못 잡혔습니다.**
(요일로 그날 수업하는 반을 고르기 때문)

`lib/day.js` 하나로 모아 고쳤습니다.

- 날짜 문자열은 **UTC 자정으로 파싱하고 UTC getter 로만** 읽습니다 → 시간대가 개입할 여지가 없음
- "오늘"만 `Intl` 로 서울 날짜를 뽑습니다
- 앱 안에서 날짜는 항상 `"YYYY-MM-DD"` 문자열로 주고받습니다

`scripts/check-timezone.mjs` 로 **UTC · 서울 · 뉴욕 · 키리바시 · 미드웨이 · 런던 · 시드니**
일곱 시간대에서 돌려 전부 같은 값이 나오는 것을 확인했습니다.

> ⚠️ 이 스크립트는 **개발용**입니다. Supabase 스니펫에 붙이면 안 됩니다 (SQL 이 아니라 셸 명령).
> 원장님은 안 돌리셔도 됩니다 — 앱에서 **오늘 날짜·요일이 맞게 뜨고
> 그 요일 반 학생이 제대로 나오는지**만 보시면 됩니다.

## ✅ 이번에 만든 것

### 회차 알림을 3개월 누적으로 바꿈
달마다 따로 판정하지 않습니다. 8월 7회 + 9월 9회면 서로 상쇄되므로

> 8월 7회(-1) · 9월 9회(+1) → **9월까지 합치면 기준과 정확히 맞습니다.
> 보강도 휴강도 하지 말고 9월까지 그대로 수업하면 됩니다.**

상쇄되는 달은 초록 `회차 맞음` 태그가 붙고 휴강 지정 버튼도 안 뜹니다.
**3개월을 다 합쳐도 남을 때만** "서비스로 할지 휴강할지" 물어봅니다.

### 금요일 = 보강만 하는 날
`설정 → 보강만 하는 요일` 에서 관리 (기본값 금).
고른 요일은 **수강료 회차와 스케줄 알림에서 빠집니다.** 보강 잡는 건 그대로.

### 공휴일 · 대체공휴일 · 낀 날 알림
**자동으로 쉬지 않습니다.** 수업이 잡힌 날만 골라서 알리고, 판단은 원장이 합니다.

- 공휴일 — "5/5 어린이날인데 수업일입니다"
- 대체공휴일 — "3/1이 일요일이라 3/2로 밀렸습니다. 학교마다 다를 수 있으니 확인해주세요"
- 낀 날 — "앞뒤가 공휴일·주말입니다"

알림에서 바로 **전체 휴강 / 반별 휴강** 지정 가능.

### 결석·보강 이관 시 주의
보강문자DB의 `결석날짜` 는 날짜 칸이 아니라 **행을 만든 시각**입니다.
(2/3 에 수십 건이 몰려 보이는 건 그날 몰아서 입력하신 것)

- 제목이 `07/14/화 장원우 결석` 형태면 → 제목에서 날짜를 읽음 (정확)
- 제목에 날짜가 없으면 → 생성일을 쓰고 미리보기에 **`추정`** 표시
- `보강날짜` 는 진짜 날짜 칸이라 그대로 믿어도 됨
