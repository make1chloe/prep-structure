# 업무루틴 — 일별

> [[업무루틴-지도]] · 지키는 규칙: [[업무루틴-규칙]] §발송·알림 · 위 층위: [[업무루틴-주별]] · 아래 층위: [[업무루틴-수업별]]

하루는 **대시보드에서 시작해서 발송으로 끝난다.** 그 사이에 수업이 있다.
「오늘 뭘 해야 하나」 를 기억하는 자리는 없다 — 대시보드가 전부 띄운다
([[dashboard-principles]] A1: 대시보드는 알림센터다).

## 1. 하루 시작 — 대시보드 한 바퀴

로그인하면 원장은 대시보드 고정. 위에서 아래로:

**① 숫자 한 줄** — 재원 N · 이달 출석률 · 오늘 리포트 (학원 상태 요약).
바로 아래 「오늘 수업 · 남은 N명/전체」 버튼 + **특이 배지 줄** — 반성문
대상 · 단원평가 막힘 · 발송 실패 · 학부모 알림 · 보강 필요 · 스케줄
특이사항 · 할일 (「남은 일」 이 안 세는 것들이라 여기 따로 뜬다).

**② 남은 일 배지** (내가 해야 하는 것 — 메뉴에도 같은 숫자):

| 배지 | 뜻 |
|---|---|
| 리포트 미작성 · 단원평가 점수 미입력 | 온 아이 중 오늘 기록이 안 끝난 것 |
| 숙제 검사 대기 | 학생이 제출했는데 아직 안 본 것 |
| 보강 미배정 | 결석은 있는데 보강을 안 잡은 것 |
| 반 미배정 / 시험범위 미등록 / 성적 미입력 | 구조가 비어 있는 것 |
| 기한 지난 할일 | 오늘까지인데 안 한 것 (앞일은 안 센다) |
| 발송할 것 | 리포트 미발송 + 교재 안내 안 나간 학생 |
| 월간리포트 (월말 3일 전부터) · 회차 미확정 (25일부터) | 때가 된 월간 일 |
| 미처리 문의 | 신규 상담 |

**③ 빠른 처리** — 보강 잡기·할일 넣기를 그 자리에서 (QuickBar, 접혀 있음).

**④ 답할 것** (저쪽이 말을 걸어온 것 — 읽던 자리에서 바로 처리):
- 학부모 요청 중 **답할 것만** (조정필요 등 — 확정된 보강은 출결 화면에)
- 신규 상담 문의 · 학부모/학생 댓글

**⑤ 카드 — 네 묶음** (8/21 재편, 「특이사항」 한 장은 해체됐다):

| 묶음 | 카드 |
|---|---|
| 🎯 오늘 수업 | 오늘 시간표 · 반성문 대상 · 단원평가 막힘(같은 단원이면 크게) · 오늘 보강·재시험 · 등원/숙제 밀림 · 클카 플래너 · 단원 없는 교재 |
| 💬 소통 · 알림 | 학부모·학생 알림(답할 것) · 보강 답변 · 발송 실패 · 신규 상담 · 댓글 |
| 💰 돈 · 운영 (기본 접힘) | 보강 필요·차액 · 회차 미확정 · 월간리포트 마감 · 곧 끝나는 교재 |
| 📅 달력 · 앞일 | 달력 · 이번 주/달 일정 · 다가오는 시험 · 결석 예정 · 휴강 · 공휴일 · 생일 |

## 2. 수업 전

| 일 | 어디서 |
|---|---|
| 결석 예정 · 보강 미리 넣기 | 출결 (`/plan`) |
| 다음 수업 숙제·공지 미리 내기 | 숙제 검사 (`/check`) 의 **「미리 내기」** — 검사하면서 다음 숙제를 정하는 실제 순서에 맞춰 여기로 옮겼다 |
| 전달사항 미리 적기 | 달력 (`/tasks`) 일정에 — 그날이 되면 오늘 수업에 그대로 나타난다 |
| 지난 수업 고치기 | **오늘 수업(`/today`)의 날짜 넘기기** (출결 화면 보강 줄에서도 `/today?d=…&open=…` 으로 그 학생 판이 열린 채 간다). 「수업 준비」 라는 화면은 이제 없다 |
| 재시험지 준비 | 「재시험지 준비해줘」 → `op=retest` 명단 + 클카 탭 |

## 3. 수업 중

오늘 수업 화면에서 그날 일이 끝난다 (유형 A — 이동 없음). 학생 한 명 판의
처리 순서는 [[업무루틴-수업별]].

- 처리할 학생만 화면에 남는다 — 일이 끝날수록 화면이 비워진다.
- 출결·숙제 ○△✕·진도 칩은 낙관적(0.1초) — 찍고 다음으로.
- 결석이 나면 그 자리에서 보강 잡기 (보강날 결석이면 「다시 보강/보강 없음」).

## 4. 하원 무렵

- **하원 안내** (늦게 가는 학생) — 사유는 자동으로 잡힌다: 단어 재시험(점수까지) ·
  **늦귀가 과제**(남은 todo) · 숙제 마무리(미제출·미흡). 원장님은 예상 시간만
  고른다. **수업 중에** 보낸다 — 리포트는 수업 끝나고 나가서 데리러 오시는
  분께는 늦다. 자동 사유는 저장하지 않고 매번 계산한다 (점수를 고치면 문구도
  따라 맞게).
- 전달사항 전달 체크 (하원 전 전달).

## 5. 수업 후 — 기록 마감과 발송

1. 데일리리포트 마무리 (문구는 자동 생성 — 확인만).
2. **발송 → 「보낼 것」**: 오늘 리포트 · 교재 안내(사용 예정일) · 월간(월말)이
   체크된 채 모인다 → 지금 보내기 / 시각 예약.
3. 경로 규칙: **재원생 = 앱 알림만** (문자 0통). 신규(상담 + 첫 등원 전)만
   문자·알림톡.
4. 자동으로 생기는 앱 알림(숙제 배정/변경 · 오늘 할 일 바뀜 · 요청(결석·
   보강·전달·질문) 확인/조정 답 · 댓글 · 보강 취소/변경)은
   **다음 :00/:30 (30분 단위) 배치**로 나간다. 즉시 나가는 것은 **사람이 그
   자리에서 누른 것** — 하원 안내, 발송 화면의 직접 보내기·재발송, 오늘
   수업의 「학생 알림·학부모 알림」(오늘 휴원 같은 당장 알릴 일).
5. 어제 써놓고 안 보낸 것도 발송 배지가 물고 있다 — 「안 보내기」 로 정리한
   것은 안 센다 (끌 수 없는 숫자 금지).
