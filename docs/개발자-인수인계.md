**절대 하면 안 되는 것 여섯**

1. **`main` 에 푸시하지 마라.** `main` = 학원이 쓰는 옛 앱, 푸시가 곧 배포(대전제-2). 작업은 `v2` 와 `claude/chloe-prompt-optimization-v2` **둘 다**에 같은 커밋을 푸시한다.
2. **마이그레이션에서 `auth.` · `storage.` · `public.` 을 건드리지 마라** — 옛 앱이 평일 저녁에 반쯤 죽는다. `check-v2only` 가 잡는다. 예외는 `9000`·`9001`(전환일에 손으로).
3. **권한 기본값을 코드에 박지 마라.** 줄이 없으면 「안 정함 = 막힘」(fail closed). `check-perm` · 32칸은 원장님이 정하신 그대로.
4. **검사를 통과시키려고 앱 코드를 고치지 마라.** 테스트 전용 뒷문 금지 — 눌러보기의 흉내(인증·보관함)는 `scripts/e2e/auth.mjs` 쪽에만 있다.
5. **재원생·학부모의 진짜 비밀번호를 건드리지 마라**(대전제-12). 리허설은 `zz_시험_` 계정 다섯 — 원장·강사·조교·학생·학부모. 앱이 발급한 계정만(`profiles.issued_by_app`) 0000 초기화.
6. **`app/globals.css` 를 손으로 고치지 마라.** 목업의 `<style>` 을 고치고 `node scripts/mockup-css.mjs` 로 다시 갈라낸다(디자인-3) — `check-mockup` 이 화소를 대조한다.

**실 DB 에 돌리는 법(㉖)** — 원장님 9/7 「다 지금해」 를 받았지만 그 세션엔 `DATABASE_URL` 이 없어 못 돌렸다. 열쇠가 있는 자리(Claude Code 환경 설정의 환경변수, 또는 개발자 PC 의 `.env.local`)에서 여섯 줄:
1. **먼저 v2 를 통째로 떠 둔다** — `pg_dump "$DATABASE_URL" --schema=v2 -Fc -f v2-before-0131.dump`(되돌릴 길 — `public` 은 안 건드린다).
