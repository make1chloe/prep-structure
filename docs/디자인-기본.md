## 1. 디자인 기본 15 — 새 앱이 지키는 줄

## 3. 이 원칙이 오늘 말씀들과 만나는 자리

- 「밝고 명랑」 → 디자인-1·2: 밝음은 **중립 바탕**에서, 명랑은 **뜻 있는 색 여덟**에서 온다. 바탕까지 색을 칠하면 파스텔이 된다.
- 「갈색 칙칙」 → 디자인-7: 글씨 대비를 노랑·주황으로 맞추려 한 것이 갈색의 뿌리.
- 「파스텔인데 안 이쁨」 → 디자인-8: 연한 바탕 + 옅은 글씨 알약(subtle)을 걷고 bold 알약으로. 회색 알약은 정보만 주는 것.
- 「대시보드라 색 여러 개」 → 디자인-2·3: 여러 색은 **뜻이 다를 때만** 여러 색. 같은 뜻에 다른 색이 붙는 순간 산만해진다(사용자 요구 4).
- 「kook.classby.kr 참고」 → 이 환경이 막아 못 봄. 캡처를 주시면 디자인-1(바탕)·디자인-8(알약 굵기)만 그 톤에 맞춘다 — 원칙 자체는 바뀌지 않는다.

## 4. 지킴

- `check-palette` — 갈색 금지(디자인-7) · 글씨 대비 37쌍(디자인-5) · 토큰 이름 = 뜻(디자인-3).
- 목업은 Playwright 로 **화면의 글씨 전부**를 훑어 대비를 잰다(스크립트 `contrast.cjs`, 목업 작업 폴더). 새 앱에도 같은 검사를 `check-layout` 옆에 세울 것 — 지을 때.
- 디자인-2(화면당 색 6) · 디자인-11(간격 4의 배수)은 아직 눈. 지을 때 검사로 올린다.
