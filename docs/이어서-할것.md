## 2. 이번 대화에서 정한 규칙 (바꾸려면 여기부터)

### 로그인
- 학생 아이디 — `chloe` + 전화 뒷 4자리 (`chloe5678`). `lib/studentId.js`
- **학부모 아이디 — 전화번호 그대로** (`01012345678`). 숫자뿐이라 학생과 안 겹친다.
  `chloe` 를 붙이면 「010 은 빼고」 를 매번 설명해야 해서 뺐다 (어머니들이 영어를 잘 모르심).
- **첫 비밀번호는 계정마다 다른 네 자리.** 아이디가 짐작되는 만큼 비번은 달라야 한다.
  0000·1234 같은 것은 안 뽑는다. `app/students/accountActions.js` 의 `makePw()`
- 형제자매 — **어머니 한 분에 계정 하나** (번호에서 나오니 저절로 그렇다)

### 알림 (워치)
- 워치는 따로 붙이는 것이 없다. 폰에 온 알림을 워치가 보여준다.
- 보내는 때는 **둘뿐** — 아이가 부를 때 · 등원 학습을 끝냈을 때
- **숙제(home)는 안 보낸다.** 밤에 울리면 알림을 통째로 꺼버리시게 된다.

### 일정 · 할일
- 일정 = 그날 그런 일이 있다 / 할일 = 내가 처리해야 하는 것
- 결석은 일정, 거기서 생긴 보강은 할일
- 달력 하나가 바탕이고 반·학생·종류로 걸러 본다 (화면을 나누지 않는다)

### 화면
- 회차 관리 — 달력은 달마다 하나, 정상 수업일은 표시 안 함, 한 해 통째로
- 학교 이름은 화면에서만 짧게 (`shortName`). 저장된 이름은 안 건드린다.
- 같은 것을 두 군데 두지 않는다 (체크·상태·기록) — 두 군데는 반드시 어긋난다

## 3. 바로 이어서 할 일 — 학생 화면 구성

원장님이 주신 구성. **아래 네 개가 아직 안 됨.**

1. ~~하원 숙제 전체목록~~ ✅
2. ~~등원 학습 전체목록~~ ✅
3. ~~당일 결석 = 약봉투·처방전 사진~~ ✅ (안내 문구만. 사진 자리는 0068 것을 씀)
4. **이번 달 현황** — 출결 · 숙제 · 단어 · 문법 테스트 결과.
   `lib/monthly.js` 의 계산을 학생용으로 줄여 쓰면 된다.
5. **일정 및 전달사항**을 한 덩어리로 — 지금은 공지가 아래쪽에 흩어져 있다
6. **수업 가이드 링크** — 설정에서 주소를 넣고 학생 화면에 띄운다. 새로 만들어야 함
7. **학생용 달력** — 수업일 · 시험 · 결석
8. **전체 순서 재배치** — 위 1~7 순서대로

원장님이 주신 순서:
```
이번달 현황 → 일정 및 전달사항 → 하원숙제(타이머+순차 / 전체목록)
→ 등원학습(지금 할 것 / 전체목록) → 선생님도움·쉬는시간
→ 수업가이드 링크 → 달력
```

## 6. 일하는 방식 (이어받는 사람에게)

- 고칠 때마다 `bash scripts/check-pages.sh` 를 돌린다. SQL 을 진짜 Postgres 에
  세 번 실행해 보고, 학생·학부모에게 뚫린 곳이 없는지도 본다.
- **화면에 안 나타나는 실수는 검사로 만든다.** 로고가 로그인으로 튕기던 것,
  홈 화면 앱이 학생 화면에서 시작하던 것 — 둘 다 눈으로는 못 찾았다.
  `scripts/check-public.mjs` · `scripts/check-routes.mjs`
- 브랜치는 `claude/student-assignment-prompt-o89q8d`, 끝나면 `main` 으로 ff 머지.
- 주석은 **왜 그렇게 했는지**를 적는다. 무엇을 하는지는 코드가 말한다.
