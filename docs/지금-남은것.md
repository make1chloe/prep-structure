# 지금 남은 것

한눈에 보는 목록. **끝난 것은 지우지 않고 맨 아래로 내린다** — 뭘 했는지
기억하려는 게 아니라, 같은 것을 두 번 묻지 않으려는 것이다.

순서는 **급한 순**이다. 위에서부터 하면 된다.

## 🔴 원장님이 해보셔야 끝나는 것

코드는 다 돼 있는데 **실제로 되는 걸 아직 못 본** 것들. 자세한 확인 방법은
[[미확인]] 에 있다.

| | 무엇 | 어디서 |
|---|---|---|
| 1 | **알림톡 한 통** — 문자는 8/3 확인됨, 알림톡은 아직 0통. 막힌 번호에 문자로 대신 나가는지도 | 발송 → 문자 문구 → 템플릿 코드 붙이고 → 발송 → 테스트 |
| 2 | **학교 2쌍 합치기** — 현송중 ← 인천현송중학교, 해송고 ← 인천해송고등학교 | 일정 → 학교 · 시험 → 학교 명단 |
| 3 | **숙제 파일** 사진 한 장 · 녹음 하나 | 학생 화면 |
| 4 | **구글 캘린더 구독** — 주소 만들고 구글에 넣기 | 일정 → 할일 · 달력 → 달력 |
| 5 | **홈 화면 아이콘** — 로고 올리고 폰에서 「홈 화면에 추가」 | 설정 → 화면 |
| 6 | **교재 · 단원 엑셀 올리기** — 양식은 다 돼 있는데 아직 한 장도 안 올라감 | 교재 → 올리기 |

## ⏸️ 멈춘 것 — 나이스 학사일정 (2026-08-11)

> 원장님: 「학사일정 일단 오류가 너무 심각해서 포기야」

**여기서 멈춘다.** 더 고치지 않고, 다음에 다시 볼 때 여기부터 읽는다.

**되는 것 (이건 그대로 쓰셔도 된다)**
- **손으로 시험 회차 만들기** — 일정 → 학교 · 시험. 나이스와 상관없이 된다.
  회차만 있으면 뒤(결석 예상 · 대비 자료 · 성적 자리)는 다 따라온다
- **학교 홈페이지 붙여넣기** — 홈페이지 표를 복사해 붙이면 회차가 된다
- **나이스 원본** 페이지 — 나이스에 **무엇이 들어 있는지** 날것 그대로 본다

**안 되는 것 · 왜**
- **나이스에 시험 날짜를 안 올린 학교가 많다.** 앱이 못 읽는 것이 아니라
  원본이 비어 있다 (나이스 원본 페이지에서 확인된다). 박문중은 홈페이지엔
  있는데 나이스엔 없었다
- 그래서 「받아오기」 를 눌러도 학교마다 결과가 들쭉날쭉하다

**다시 볼 때 첫 물음** — 「나이스를 계속 볼 것인가」.
원본이 비는 학교가 절반이면, 받아오기를 붙들기보다 **회차를 손으로 · 홈페이지
붙여넣기로 채우고 나이스는 참고로만** 두는 편이 낫다. 그 결정을 먼저 한다.
조사·설계는 [[시험-일정-조사]] 에 남아 있다.

## 🟠 아직 안 한 것

7. **수강료 차액을 다음 달에 반영** — 지금은 금액만 보여준다.
   휴강으로 회차가 빠지면 「보강 n회 · 차액 얼마」 까지는 나오는데,
   다음 달 청구에 실제로 빼주는 것은 손으로 해야 한다
8. **강사·조교 권한 분리 — 나머지** (0079 는 첫 겹만)
   · 지금 갈라둔 것: **돈과 열쇠** (수강료 · 발송 연동 · SQL · 이관)
   · 안 갈라둔 것: 성적 입력 · 학생 정보 수정 · 발송 실행
   · 표 마흔 개를 동시에 건드리는 일이라 따로 한다
9. **교재 안내 문자 발송 기록 이관** — 어디 있는지 찾았다 (아래 §17 참고).
   `/import` 에 탭을 하나 붙이면 된다
10. **재원생 `school` 글자 칸을 읽는 곳 정리** — 예순몇 군데.
    지금은 방아쇠가 `school_id` 를 따라 채워주고 있어서 급하지 않다
11. **시험대비 페이지** — 아직 없다. 무엇을 담을지는 조사해 두었다
    → [[영어시험-특징]] (내신은 학교마다 · 모의고사는 전국 같은 날 ·
    수능은 11월 하나). **회차가 있어야 만들 수 있다**

## ✅ 끝난 것 (2026-08-05)

### 고친 문제
- **시험 기간 결석이 반 전체에 찍히던 것** — 이제 그 시험을 보는 아이에게,
  그 아이의 시험 날짜에만. 덤으로 **숨긴 시험이 결석 예상에 남아 있던 것**도
- **내신 자료가 할일에 안 뜨던 것** — 할일 화면 위에 마감 순서로
- **일정 배정이 조용히 아무에게도 안 가던 것** — 학교를 글자로 쳐서
  「신송중」과 「신송중학교」가 갈리면 그랬다. 이제 명단에서 고른다 (0077)
- **엑셀 단추 크기가 안 맞던 것** — `btn-sm` 하나가 빠져 있었다
- **로고가 안 바뀌던 것** — 원인 셋을 차례로 (브라우저 캐시 → 판이 늘어난 것 →
  권한만 주는 SQL 이 검사에 안 걸리던 것)

### 새로 만든 것
- **단어시험 개수 자동** — 지난 수업 단어 숙제의 범위 단원을 더해서
- **루틴이 범위 단원까지** 채운다
- **할일 달력** — 일정 · 할일 · 시험 · 휴강 · 방문상담 · 레테 · 보강 · 결석
- **구글 캘린더 구독** (앱 → 구글, 0078)
- **수업 준비 → 지난 수업 고치기** — 그 날짜 그 학생 판이 열린 채로
- **학부모 계정** (0079) — 형제는 계정 하나로 둘 다 본다
- **로고 올리기** (0080·0081) — 홈 화면 아이콘 · 왼쪽 위 로고
- **화면 테마** — 시스템 / 밝게 / 어둡게
- **재원생 좌우 2분할 + 반·요일·학교·학년 묶어 보기**
- **메뉴 위계 다시** — 오늘 / 학생 / 교재 / 일정 / 발송 / 운영 / 설정
- **단원 엑셀 내려받기** — 빈 양식에서 다시 안 쳐도 되게

### 답이 난 것
- **재시험 셈법** — 1번에 통과하면 「통과」, 재시험이면 「재시험 통과」,
  그 뒤는 「3차 통과」. 학부모 화면은 「6번 중 4번 통과 (그중 재시험 1번)」
- **토·일 보강** — 기본은 금요일, 시험이 월요일이면 토·일에도.
  앱은 이미 이대로 된다 (보강 날짜는 수업일로 안 막는다)
- **1~3월 출결** — **안 본다.** 2026년 8월부터 출결 관리 시작
- **교재 안내 발송 기록** — 노션 **교재구매DB** 에 있다.
