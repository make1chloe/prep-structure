# 숙제를 배정하면 내 할일이 생긴다

관련: [[2026-07-27-하원안내]] · [[미해결-클로이영어앱]]

---

## 문제

단원평가 대비 복습을 숙제로 내주면, **다음 수업 전에 내가 문제를 출제해야 한다.**
그런데 그건 어디에도 안 남고 원장님 머릿속에만 있었다.

## 어떻게 했나

숙제 항목마다 **"이걸 배정하면 이런 할일이 생긴다"** 를 적어둔다.
이름을 코드에 박지 않았다 — 나중에 다른 숙제에도 붙일 수 있어야 하기 때문이다.

`교재 · 숙제 → 학습 항목` 표에 **내 할일 자동 생성** 칸이 하나 늘었다.

| 항목명 | 내 할일 자동 생성 |
|---|---|
| 단원평가 대비 복습 | `{학생} 단원평가 출제` |
| 수행평가대비 워크북 | (비어 있음 — 안 만든다) |

`{학생}` 자리에 이름이 들어간다. **비우면 안 만든다.**

0028 을 실행하면 이름에 `단원평가` 가 들어간 항목에 자동으로 켜진다.
`단원평가 대비 복습` 항목도 없으면 만들어 둔다.

## 언제 생기나

오늘 수업에서 그 숙제를 **다음 숙제로 배정하고 저장하는 순간.**

```
할일
  자동   7/29 (수)   김O윤 단원평가 출제        수업 준비
                     7/27 수업에서 '단원평가 대비 복습' 을 배정했습니다.
```

- **마감일 = 그 학생의 다음 수업일.** 숙제를 그때 검사하니까 그때까지 준비돼 있어야 한다.
  학생이 다니는 반들의 요일을 합쳐서 계산한다.
- 분류는 **수업 준비** 로 들어간다.
- `자동` 태그가 붙는다 — 사람이 만든 할일과 구분된다.

## 두 번 생기지 않는다

`tasks.auto_key` 에 `prep:{학생}:{항목}:{날짜}` 로 열쇠가 박히고,
그 열쇠에 유니크 인덱스가 걸려 있다. 리포트를 다섯 번 저장해도 할일은 하나다.

마감일을 옮겨놨어도 다시 저장할 때 되돌려놓지 않는다.

## 배정을 취소하면

**아직 안 한 할일은 같이 사라진다.** 잘못 배정한 걸 되돌리면 할일도 되돌아간다.
**이미 끝낸 할일은 건드리지 않는다** — 한 일은 한 일이다.

## Supabase SQL 붙여넣는 법 (다시)

**덧붙이는 게 아니라 통째로 갈아끼우는 것입니다.**

1. SQL Editor → Untitled query 안을 클릭
2. **Ctrl+A → Delete** (지난번 내용을 지운다)
3. `설정 → Supabase SQL → 전체 복사` 한 것을 붙여넣기
4. Run

지난번 내용 아래에 계속 덧붙이면 같은 걸 두 번·세 번 실행하게 되고 줄 수만 늘어난다
(사고가 나지는 않는다 — 전부 `if not exists` 로 되어 있다).

지금 `한번에_실행.sql` 은 **1,167줄** 이다. 2,500줄이 나왔다면 덧붙여진 것이다.
설정 화면의 SQL 카드에도 줄 수를 띄워두었으니 붙여넣은 뒤 비교하면 된다.
