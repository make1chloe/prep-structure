# 기본학습(노션) 정리 — 2026-08-14

원장님이 노션 기본학습 표를 통째로 주셨다 (학생 여러 명 × 공지·단어·독해·
문법·영작·듣기·노트·내신·특강·내신온라인). 여기서 **반복되는 패턴**을
뽑아 정리한 것. 루틴·학습항목 설계의 원본 근거다.

## 1. 문법 — 거의 모든 학생이 같은 6줄 묶음 (단원만 전진)

> 설명읽고 형광펜 중요표시 & 개념노트에 문답노트 형식으로 요약정리
> · 강의듣고 문답노트 형식으로 정리 (클카-문법강의)
> · 문답노트 이용해서 셀프 구두테스트 3회 녹음인증
> · 클카-문법훈련 완료
> · 문제풀기
> · 단원평가 대비 복습

**발견** — 문법은 여러 회차짜리 사이클이 아니라, **매 수업 같은 묶음을
단원만 바꿔 내는 1단계 반복**으로 보인다. (8/13 본보기 4회차 초안은 이와
다르다 — 원장님 확인 후 교체할 것.)

변형:
- **인강 병행**: 「강의듣고 문답노트」 줄이 있음/없음 (클카 문법강의)
- **간단 교재**(서술형제패 · 기적의문법+영작 · 3300제): 「설명읽고 형광펜 &
  문제풀기」 만
- 3300제는 주말: 4페이지 (4가지 문법 1페이지씩)

오답은 노트숙제로 따로: 「문법 오답노트 <틀린 문제 3개/5개/모두> 쓰기
(영어문장·해석·정답의 근거)」 — 개수 기준이 학생마다 다르다.

## 2. 단어 — 「등원 전 완료」 가 기본형

- 기본: **등원전 클래스카드 필수학습 완료**
- 미통과 페널티(학생별): 스펠 100% 추가 / 틀린 단어 영+한 10번 쓰기 /
  통과했어도 숙제 미완료면 동일
- 시험 방식 명시: 「수업 시작 시 뜻+스펠링 주관식」 · 「뜻만 day2개
  컷트라인 -4」 (→ 앱의 단어시험 설정과 같은 축)
- 교재 라인: 오토보카 dayN 풀고 채점 / day5 영+한 2번 쓰기 /
  단어워크북 셀프테스트+채점 / 교재 2단원 문제풀고 암기

## 3. 독해 — 교재 라인별로 다르지만 뼈대는 [예습]/[복습]

뼈대:
- **[예습]** 모르는 단어 찾아 뜻 쓰기 → 문제풀기 (+ 기호표시 후 QR 확인 /
  채점 후 세모별표)
- **[복습]** 워크북 풀기 → 해석 쓰기(끊어읽기 표시)
- **클카**: 낭독·녹음·암기 100% + 스크램블 점수 기준
  (4000/6000/8000/지난 점수 경신 — 라인·단계별로 다름)

라인별 변형:
- **자이스토리**: 시간 재서 · **모든 문제에 근거 표시** · 모르는 단어는
  지문+선택지 모두 · 해석 안 되는 문장 형광펜 · 딸림 문제까지
- **동시통역류**: step2만 3번씩 녹음 인증
- **쇼츠형**: 쇼츠 보고 빈칸 + 대본 녹음 3번 카톡 인증
- 별표 문제는 「문장/해석/SVOCM 오답노트」

## 4. 영작 — 설명읽고 형광펜 + 문제풀기 (기적의 문법+영작 · 기적의 영어문장)

## 5. 내신문제 — 「Unit 1개 개념정독+형광펜+문제풀기, 단원 끝나면 워크북도」

## 앱에 반영할 것 (원장님 확인 후)
1. **문법 본보기 루틴을 1단계 반복형으로 교체** (위 6줄 = home,
   등원 = 단어시험·단원평가·새 단원 설명)
2. 빠진 학습항목 등록: 강의듣고 문답노트(클카 문법강의) · 클카 문법훈련 ·
   단원평가 대비 복습 · 문법 오답노트
3. 독해는 교재 라인별 루틴 — [예습]/[복습] 뼈대 + 라인 변형
4. 스크램블 점수 기준·오답노트 개수는 학생별 값 — 루틴이 아니라
   학생/단어시험 설정 축
