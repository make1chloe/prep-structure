# 고민 · 문제점

원장님이 「고민」 또는 「문제점」이라고 하시면 **고치지 않고 여기 적어둡니다.**
쓰시다가 걸리는 것을 그때그때 말씀하시고, **나중에 모아서 한 번에** 고칩니다.

바로 고치면 이야기가 끊기고, 급한 것과 급하지 않은 것이 섞입니다.
적어두면 나중에 함께 보면서 **묶어서 풀 수 있는 것**을 알아볼 수 있습니다.

- 상태는 **적음 / 고치는 중 / 고침** 셋뿐입니다.
- 고친 것은 지우지 않고 밑으로 내립니다 — 왜 그렇게 됐는지가 남아야 합니다.

## 적음

### 1. 엑셀 교재명이 기존과 달라서 교재가 두 개가 됨
*2026-08-02*

단원 엑셀을 올릴 때 교재를 **이름으로** 찾습니다. 앱에 있는 이름과 엑셀에
적힌 이름이 한 글자라도 다르면 같은 교재로 못 알아보고 **새 교재를 만듭니다.**
띄어쓰기나 판형 표기(2025 개정 / 개정판)만 달라도 그렇습니다.

그러면 같은 교재가 두 권이 되고, 학생 배정과 진도가 둘로 갈립니다.

생각해볼 것
- 올리기 전에 **비슷한 이름을 찾아 "이 교재 말씀이신가요?"** 하고 물어보기
- 새 교재를 만들기 전에 **한 번 확인**받기 (지금은 조용히 만듭니다)
- 이미 갈라진 교재를 **합치는** 기능 (단원·배정·진도를 한쪽으로 옮기기)

### 2. 교재 단원을 엑셀로 만드는 것 자체가 복잡함
*2026-08-02*

단원을 정리하다 보면 **엑셀 구조를 바꿔야 할 때**가 있습니다.
대단원/중단원/소단원 세 칸으로 되어 있는데, 교재마다 층이 다르고
어떤 교재는 단원이 없고 문제번호만 있습니다.

지금은 엑셀을 고쳐서 다시 올리는 방식인데, 그 엑셀을 만드는 일이 이미 일입니다.

생각해볼 것
- 엑셀 없이 **앱에서 바로 층을 만들고 옮기는** 편집기 (지금도 옮기기는 되지만
  한 번에 여러 층을 다루기는 어렵습니다)
- 지금 들어 있는 단원을 **엑셀로 내려받아** 고쳐서 다시 올리기
  (빈 엑셀에서 시작하지 않아도 되게)
- 교재별로 층 이름을 정해두기 (Part/Unit/Day 처럼)

### 3. 재원생 정보를 카드나 접기로 보는 게 나을지
*2026-08-02*

지금은 표입니다. 열을 고를 수 있게는 했지만, 폰에서는 여전히 가로로 넘칩니다.

생각해볼 것
- 한 학생을 **카드 한 장**으로 (이름 크게, 나머지는 접어두고)
- 표와 카드를 **골라서 볼 수 있게**
- 폰에서는 카드, 컴퓨터에서는 표로 저절로 바뀌게

### 4. 단어시험 통과·미통과를 저절로 기록할 수 있을지
*2026-08-02*

재료는 이제 다 있습니다.
- 학생의 **통과선**과 **한 번에 보는 개수** (재원생 → 단어시험, 0070)
- 교재의 **소단원당 단어 개수** (교재 → 단어, 0070)
- 그날 나간 **범위**(단원)

그러면 "오늘 몇 개 중 몇 개" 를 앱이 알 수 있고, 틀린 개수만 넣으면
**통과·미통과가 저절로** 정해집니다.

확인할 것
- 지금은 오늘 수업에서 **전체 개수를 손으로** 넣고 있습니다 — 그 자리를
  범위에서 자동으로 채우면 되는지
- 범위가 여러 단원이면 개수를 **더해야** 하는지
- 통과선이 학생마다 다르면 리포트 문구도 학생마다 달라지는지
  ("18/20 통과" vs "18/20 미통과" 가 같은 점수에서 갈립니다)
- 재시험 결과는 어느 쪽으로 세는지
