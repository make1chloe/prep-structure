## 1. 학습 항목에 학습 방법 쓰기 ⭐ 1순위

단원 데이터와 무관하게 **지금 바로** 할 수 있고, 나중에 학생용 페이지의 핵심이 된다.
한 번 쓰면 모든 학생·모든 날짜에 재사용된다.

- [ ] 앱 → **학습 항목** 메뉴
- [ ] 자주 쓰는 항목부터 `수정` → **학습 방법** 칸에 작성
	- [ ] 단어(교재)
	- [ ] 단어(온라인)
	- [ ] 독해
	- [ ] 워크북
	- [ ] 문법
	- [ ] 영작
	- [ ] 오답노트
	- [ ] 문장암기(온라인)
	- [ ] 셀프테스트(종이/녹음)
- [ ] 안 쓰는 항목은 **삭제 말고 숨기기** (지난 기록 보존)

작성 예시
```
1. 단어를 소리 내어 읽으며 3번 쓰기
2. 뜻을 가리고 셀프테스트
3. 틀린 단어만 단어노트에 정리
```

## 2. 교재 목록 정리 ⭐ 2순위

단원 엑셀은 **교재명으로 매칭**되므로, 먼저 정리해두면 나중 업로드가 매끄럽다.

- [ ] **중복·오타 교재 정리**
	- [ ] `20206 내신콘서트 2-1 동아이병민` ↔ `2026 내신콘서트 2-1 동아이병민` (오타 중복)
	- [ ] `3800제1` ↔ `3800제1 중간기말고사 대비편`
	- [ ] `2026 백발백중 2-1 동아이병민` ↔ `2026백발백중 2-1 동아윤정미` 계열 확인
- [ ] **안 쓰는 교재 상태 변경** → `절판` / `중단` (목록에서 사라져 채울 대상이 줄어듦)
- [ ] **영역 비어 있는 교재 21권** 채우기 (독해/문법/단어/듣기/영작/내신)
- [ ] **총 페이지 입력** — 단원을 올린 뒤에도 계속 쓰인다
- [ ] `추후결정` 교재 정리

## 3. 오늘 수업 실제로 써보기 ⭐ 3순위

단원 없이도 전부 돌아간다. **며칠 써보면 고칠 게 가장 정확하게 나온다.**

- [ ] 출결 찍기 (등원 버튼 / 지각·결석·보강)
- [ ] 단어·문장 테스트 점수 입력
- [ ] 숙제 검사 → ○ 완료 / △ 미흡 / ✕ 미제출
- [ ] 다음 숙제 배정 (하원 전)
- [ ] 태도 별점
- [ ] 공지·전달사항 써보기 (전체 / 반별 / 학교학년별 / 개인별)
- [ ] 하원 전 전달 체크 눌러보기
- [ ] **불편한 점 메모** → 이 파일 맨 아래 "고쳐야 할 것"에 적기

## 4. 반에 교재 배정

- [ ] 앱 → **반** → 반 선택 → 아래 **교재 배정**
- [ ] 반마다 쓰는 교재 체크 → `교재 저장`
- 단원이 없어도 지금 해두면, 나중에 단원 올리는 순간 진도 화면에 자동으로 나타난다

---

## 5. 단원 데이터 채우기 (오래 걸림 — 나눠서)

**전부 채울 필요 없다.** 지금 학생들이 실제로 쓰는 교재부터.

- [ ] 교재 페이지에서 `단원 없는 교재만` 체크 → 남은 목록 확인
- [ ] **규칙적인 교재**는 엑셀 말고 `⚡ 단원 한 번에 만들기` (한 권 10초)
	- Unit 1~20 + 시작/끝 페이지 → 균등 분할 자동
	- 리딩튜터 / 능률보카 / 워드마스터 / 자이스토리 계열
- [ ] **불규칙한 교재**만 엑셀로 (`클로이영어_단원_입력용.xlsx`)
	- 내신 교재, 모의고사류
	- 열: 교재명 / 출판년도 / 대단원 / 중단원 / 소단원 / 단원명 / 활동명 / 시작페이지 / 끝페이지 / 총 분량
- [ ] 채우기 전까지는 오늘 수업에서 **페이지로 진도 기록** (`지금 84 / 160p`)

> 단원을 나중에 올려도 **다시 할 일 없음.** 그 교재만 자동으로 단원 방식으로 바뀌고,
> 페이지로 적어둔 기록과 숙제 기록은 그대로 남는다.
