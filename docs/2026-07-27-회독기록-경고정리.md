## 1. SQL 파일은 Supabase 안에 없다

SQL Editor 의 **Untitled query** 는 그냥 빈 종이다. 붙여 넣을 내용은
깃 저장소 안 `supabase/한번에_실행.sql` 에 있다.

매번 깃허브를 뒤지는 게 번거로워서 앱 안에 넣었다.

> **설정 → Supabase SQL → 전체 복사**

`/settings/sql` 이 파일을 그대로 읽어서 보여준다. 붙여넣기 순서도 같이 적어뒀다.
(Vercel 배포에 `.sql` 이 안 딸려가서 `next.config.mjs` 의
`outputFileTracingIncludes` 로 명시해 뒀다. 못 읽으면 깃허브 링크로 넘어간다.)

## 2. 회독을 올려도 진도를 지우지 않는다

전에는 `⟳ 다음 회독으로` 를 누르면 끝낸 단원을 **지웠다.**
1회독을 언제 어디까지 했는지가 그대로 사라졌다.

이제 회독을 붙여서 쌓는다. `student_unit_progress` 의 기본키가
`(학생, 단원)` → `(학생, 단원, 회독)` 으로 넓어졌다.

- 오늘 수업의 진도율 = **지금 회독** 기준 (2회독으로 넘기면 0%부터 다시)
- 학생 기록의 교재 사용 기록에 **회독마다** 한 줄씩

```
Word Master 중등 실력          단어  사용중  85%
  1회독 100% (60/60) · 2026-03-04 ~ 2026-06-18
  2회독  35% (21/60) · 2026-06-25 ~ 지금 · 진행중
```

회독이 1이면 접혀 있고, 2회독 이상일 때만 펼쳐진다.

## 3. 경고 월간 정리

경고를 계속 끌고 가면 학기가 갈수록 누구나 반성문 대상이 된다.
한 달에 한 번 0으로 되돌린다.

### 어디에 뒀나

**오늘 수업 맨 위** — 달이 바뀌고 처음 여는 날, 경고가 남아 있는 학생이 있을 때만 뜬다.

```
8월이 시작됐습니다 — 지난달 경고를 정리할까요?   [3명]
지금 경고가 남아 있는 학생: 김O윤, 박O서, 이O준
정리해도 기록은 그대로 남습니다. 다음 달 경고만 0에서 다시 셉니다.

[전원 정리하기]  [이번 달은 그냥 두기]
```

설정 화면에 버튼을 두면 한 달에 한 번 들어갈 일을 기억해야 한다.
매일 여는 화면이 먼저 물어보는 쪽이 맞다고 봤다.

- **전원 정리하기** — 경고가 쌓인 학생만 골라 `warning_actions` 에 `reset` 한 줄씩
- **이번 달은 그냥 두기** — `integrations.warning_reset.config.skip = "2026-08"`.
  다음 달이 되기 전에는 다시 뜨지 않는다

### 지워지지 않는다

정리는 **카운트만** 0으로 돌린다. 학생 기록 → **경고 기록** 에 전부 남는다.

```
반성문 씀   2026-05-12
유예        2026-06-09   시험기간이라 이번엔 넘어감
경고 빼줌   2026-06-20   2026-06-18 경고 제외 · 병원
월간 정리   2026-07-01   2026-07 월간 정리
```

`kind` 에 `reset` 이 하나 늘었을 뿐이라 표를 새로 만들지 않았다.

## 4. 겸사겸사 고친 것

### `/today` 의 경고 계산이 죽고 있었다

```js
import { tally } from "@/lib/warnings";   // 함수
...
const tally = new Map();                  // ← 같은 함수 안에서 가려버린다
...
tally(mine, wActions, rule)               // TypeError: tally is not a function
```

`const` 가 함수 전체를 덮어서 아래쪽 호출이 Map 을 부르고 있었다.
빌드는 통과한다. 지역 변수를 `noticeTally` 로 바꿨다.

### 남아 있던 시간대 버그

`new Date().toISOString().slice(0,10)` 이 세 군데 남아 있었다.
서버가 UTC 라 밤에 누르면 하루 전 날짜로 기록된다.

- `stayActions.js` 의 `waiveWarning` · `settleWarnings` → `todaySeoul()`
- `WarnBox.jsx` → 서버가 준 `date` 를 그대로 쓴다

### 단어 오답 허용 기본값

설정 저장 코드에 `Number(warn.wordWrongPct) || 80` 이 남아 있었다.
80% 오답까지 통과가 될 뻔했다. 10 으로 고치고 0~100 으로 잘랐다.
