# 말 사전 — 화면에 쓰는 말은 업계 표준 · 초5 도 알아듣는 말 (대전제-23)

> 원장님 (2026-09-15): 「하나부터 열까지 단어가 왜 다 이따위로 쓰고있는데 대한민국 어느 선생님 학원강사가 이걸 알아듣냐 야 메뉴명 설명 좀 어휘선택 업계표준으로좀써」 · 「영어일이 뭐지 영어시험일인갚」 · 「입회상담은 신규상담으로 써」

- **지금** 열의 말은 화면 글(메뉴 · 단추 · 카드 제목 · 문장 · 오류 글)에 쓰지 않는다. **나중** 열의 말로 쓴다.
- 「찾기」 열은 `scripts/check-words.mjs` 가 쓰는 정규식이다(주석을 뺀 화면 글자 토큰 · app + lib 전체에서 센다 · 상한 0). 비어 있으면 검사가 안 센다(뜻이 겹치는 흔한 말).
- **이름은 명사로 쓴다**(원장님 2026-09-18 「이런 말 쓰지말고 명사화하라고 한거 아직 안한거지?」). 메뉴 · 카드 제목 · 화면 이름에 **의문문·서술문을 쓰지 않는다** — 「누가 무엇을 보나」 ✗ → 「권한 설정」 ○. 지킴: `check-words` 의 「이름은 명사」 줄.
- 새 말이 필요하면 **여기에 먼저** 적는다. 우리끼리 말(판 · 손 · 파도 · 띠)은 코드 주석과 문서에만 쓴다.
- 그대로 두는 말(업계에서도 그렇게 부른다): 마감 · 루틴 · 보드 · 진도 체크 · 숙제 검사 · 데일리리포트 · 월간 리포트 · 신규 상담(원장님 9/15) · 반 · 오늘 수업.
