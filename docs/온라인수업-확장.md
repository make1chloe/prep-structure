# 온라인 수업으로 확장하기 — 장기 구상

> 관련: [[할일-클로이영어앱]] · [[미해결-클로이영어앱]] · [[ROADMAP]] · [[PRINCIPLES]]

**아직 아이디어 단계다.** 지금 만들 것이 아니라, 나중에 시작할 때
처음부터 다시 생각하지 않으려고 적어둔다. 결정된 것은 하나도 없다.

---

## 한 줄 결론

**화상 강의를 하지 않는다.** 정해진 시간에 접속해 자기 진도를 하고,
제출하면 검사해서 리포트로 돌려주는 **관리형**으로 간다.
지금 하는 개별진도 수업을 장소만 바꾼 것이지, 새 상품을 만드는 게 아니다.

---

## 1. 왜 우리가 유리한가

우리 수업의 본체는 **강의가 아니라 관리**다. 전원 개별진도이기 때문에
"반 전체가 같은 진도를 나가는 강의"를 옮길 필요가 없다.
**배정 → 검사 → 리포트** 이 사슬만 옮기면 수업이 그대로 성립한다.

앱에 이미 있는 것:

| 있는 것 | 온라인에서 하는 역할 |
|---|---|
| 학생용 페이지 `/me` — 사진 · 녹음 · 체크리스트 제출 | 온라인 학생의 수업 화면 그 자체 |
| 등원용 ↔ 집용 항목 치환 (`home_item_id`) | 구두테스트 → 셀프녹음테스트. **온라인의 핵심 장치가 이미 있다** |
| 출결 상태 `온라인` + 리포트 문구 | 그날 온라인으로 했다는 기록 |
| 등원 전 숙제 검사 · 부여 | 학생이 눈앞에 없어도 검사하는 흐름 |
| 데일리리포트 발송 + 댓글 | 학부모 신뢰 장치 |
| 경고 · 반성문 · 재시 | 안 하면 불이익이 있다는 규칙 |

**즉 온라인반은 새 시스템이 아니라, 지금 시스템의 다른 사용법이다.**

## 2. 조사 — 지금 돌아가는 온라인 수업 모델 (2026-07-31)

### A. 라이브 화상 강의형
줌·전용 프로그램으로 실시간 강의. 학습 파일 띄워 판서·첨삭, 그 자리에서 퀴즈·채점.
오프라인 수업을 그대로 송출하는 **하이브리드** 변형도 있다.

> ⛔ **우리는 안 한다.** 조사에서 반복해서 나온 지적이
> "강사 혼자 온·오프를 동시에 관리하는 건 힘들다" 였다.
> 1인 운영에서 가장 먼저 무너지는 형태다.

### B. 1:1 화상 튜터형
시간 단위로 판다. 1회 신청도 가능. 수업 후 데이터 분석 · **월말평가서**.
→ 회화 상품이라 내신 · 개별진도와 성격이 다르다.

### C. 플랫폼 결합 관리형
콘텐츠는 기성 플랫폼(리딩게이트 · 리딩앤 · 런피아 등)이 대고 **학원은 관리만 판다.**
소규모 학원이 온라인반을 여는 가장 흔한 경로.
리딩게이트의 **리딩지수**처럼 누적 숫자를 계속 보여주는 게 동력이다.

> 우리는 자체 앱이 이미 그 이상을 한다. **플랫폼을 살 이유가 없다.**

### D. 관리형 캠스터디 · 온라인 자습 감독형 ⭐
가르치는 게 아니라 **공부하는 시간을 관리해서 판다.** 온라인에서 가장 확실한 형태.

- **교시제** — 1시간 단위로 쪼갬. 오전 8시 온라인 출석체크로 시작
- **실시간 관제** — 캠을 보며 경고 · 벌점 · 강제 퇴실
- **전날 계획 세우기 → 5분마다 알림 → 10분 이상 지연 시 전화**
- 출석일수 · 주간 공부시간에 벌점, 일 · 주 · 월 달성률 공개
- 열품타 방식: 영상이 아니라 **20초마다 자동 사진**을 그룹에 공유
  (부담이 적고 통신량도 적다 — 우리가 쓴다면 이 방식)

### E. 비동시 제출–첨삭형 ⭐
실시간 수업이 아예 없다. 자기 시간에 하고 제출하면 채점·코멘트해서 돌려준다.

- 쿠몬 커넥트 — 태블릿으로 **종이 학습지와 같은 교재·같은 방식**을 그대로 옮김.
  끝내는 즉시 제출 → 빠른 채점 → **학습지에 직접 밑줄·코멘트**를 써서 스스로 고치게 함
- 로그인할 때마다 뜨는 **짧은 메시지**(진도 안내 · 칭찬 · 자주 틀리는 것)
- **누적 학습 기록을 학생이 직접 열어본다**

## 3. 잘 되는 곳의 공통 장치

모델이 달라도 성황인 곳은 아래를 거의 다 갖고 있었다.

| 장치 | 실제 사례 |
|---|---|
| 콘텐츠가 아니라 **붙잡아 두는 시간**을 판다 | 교시제, 8시 출석체크 |
| 제출 → 피드백 **사이클을 짧게** | 끝내면 바로 제출, 바로 채점 |
| **통과 기준 + 당일 재시** | 성취도 80% 미만은 그날 2회차 재시 |
| **눈에 보이는 누적 숫자** | 리딩지수, 학습기록, 달성률, 월말평가서 |
| 계획은 학생이 세우고 **시스템이 쫀다** | 전날 계획 → 5분 알림 → 10분 지연 시 전화 |
| **불이익이 실제로 있다** | 벌점, 강제 퇴실, 휴대폰 제출 |
| 학부모 **정기 보고가 고정** | 월말평가서, 영역별 학습상태 |

> 온라인이 망하는 지점은 가르침의 질이 아니다.
> **아이가 안 하고 · 안 한 게 안 걸리고 · 학부모가 그걸 모르는 것**이다.
> 위 장치는 전부 그 셋을 막는 도구다.

## 4. 우리 형태 — D + E

**정해진 시간에 접속(D) + 제출하면 검사해서 돌려줌(E).**

```
온라인 학생의 하루

  17:00  접속 — 오늘 할 것이 /me 에 이미 깔려 있다 (미리 작성으로 배정)
         가벼운 인증 (사진 1장 또는 시작 버튼)
  17:00~ 자기 진도 — 단어 · 독해 · 워크북
         막히면 댓글로 질문
  18:30  제출 — 사진 · 녹음 · 체크리스트
  ~19:30 미제출이면 알림, 그래도 없으면 학부모에게
  밤     원장님이 검사함에서 몰아서 검사 → ○△✕ + 한 줄
         → 데일리리포트 자동 발송 (제출물 요약 포함)
         → 다음 숙제 배정
  주 1회 화상 10분 — 구두테스트 · 얼굴 보고 확인
```

**주 1회 화상은 꼭 넣는다.** 매일 할 필요는 없다.
"온라인이어도 선생님이 직접 확인한다" 가 학부모에게 주는 안심이 크고,
셀프녹음만으로는 안 되는 발음 · 태도가 그때 잡힌다.

## 5. 앱에 없는 것 (만들 때 할 일)

| 조사에서 나온 장치 | 우리 앱 | 필요한 일 |
|---|---|---|
| 제출 → 즉시 첨삭 | ⚠️ 제출은 되는데 **몰아서 검사하는 화면이 없다** | **검사함** 화면 신설 |
| 온라인 학생 개념 | ❌ `온라인` 은 그날 찍는 출결일 뿐 | 학생에 **수강 형태**(대면/온라인/혼합) |
| 교시제 · 접속 시간 | ❌ 없음 | `/me` 의 `timerActions.js` 를 살려 **학습 시간 기록 → 리포트에 싣기** |
| 미제출 재촉 | ❌ 없음 | 마감 시각 → 학생 알림 → 학부모 알림 (자동) |
| 학생에게 보이는 누적 숫자 | ⚠️ 회독·진도율·점수는 쌓이는데 **학생에게 안 보인다** | `/me` 에 성장 지표 한 줄 |
| 온라인 단어시험 | ❌ 셀프녹음으로 대체 중 | `wordTest.js` 설정이 이미 있으니 **응시 화면 + 자동 채점** |
| 요금 · 회차 | ❌ 온라인 단가 규칙 없음 | 아래 6번에서 정해야 함 |

**중요:** 온라인 학생도 **수업일을 요일로 정한다.** 등원 대신 "그날 검사받는 날".
이래야 회차 · 수강료 · 리포트 로직을 **그대로 재사용**한다. (원칙 1)

### 선행 조건

[[할일-클로이영어앱]] 1순위인 **학습 항목에 학습 방법 쓰기**가
온라인에서는 선택이 아니라 **필수**다. 대면에서는 말로 알려줄 수 있지만
온라인 학생에게는 **그 글이 곧 선생님**이다. 시작 전에 자주 쓰는 9개 항목은 채워야 한다.

## 6. 원장님이 정해야 하는 것

- [ ] **대상** — 신규 모집인가, 기존생 전환인가
      · 추천: **기존생 전환부터.** 시험기간 · 방학 · 이사 · 아파서 못 나오는 학생을
        붙잡는 용도. 퇴원 방지 상품이라 리스크가 없고 이미 아는 학생이라 관리가 통한다.
        (보강문자DB 291건 = 결석 관리 수요가 그만큼 있다는 뜻)
- [ ] **요금** — 대면 대비 몇 %? 혼합은?
- [ ] **회차 · 결석** — 온라인 수업일에 제출을 안 하면 결석인가, 이월인가?
      휴강은 안 깎고 보강으로 채운다는 원칙을 온라인에 어떻게 적용할지
- [ ] **정원** — 검사에 학생당 몇 분 걸리는지 재봐야 정원이 나온다
- [ ] **테스트 신뢰도를 어디까지 요구할 것인가**
      · 셀프녹음으로 충분한가 / 앱 응시 + 시간제한까지 갈 것인가 / 화상 구두만 인정할 것인가
- [ ] **검사 시간을 언제로 둘 것인가** — 금요일(보강만 하는 날)이나 등원 전 시간대에 몰기
- [ ] 온라인 학생끼리 반을 묶을지, 대면 반에 섞을지

## 7. 제도 — 먼저 확인해야 함 ⚠️

**초 · 중 · 고 대상 원격교습은 학교교과교습학원 범주에 들어간다.**
온라인이라고 등록 없이 되는 게 아니다.

- 원격교습용 **서버 등 장비 구축** + 학원법 · 건축법상 **학습자 상담용 사무실 공간** 등
  시설 · 설비 기준을 충족해야 한다
- 성인 대상이면 학원법이 아니라 **평생교육법 제33조 원격평생교육시설 신고**
- 정식 등록해야 **부가세 면세**를 받는다
- 순서: 교육청 원격학원 등록 → 사업자등록증 → 구매안전서비스 확인증 → 통신판매업 등록증

> 우리는 **이미 오프라인 학원이 등록되어 있다.** 새로 만드는 게 아니라
> **기존 등록에 원격교습을 추가(변경등록)** 할 수 있는지가 관건이다.
> 기존 학원 설비를 쓰므로 사무실 요건은 이미 충족일 가능성이 높다.
> **지역 교육지원청마다 해석이 다르니 관할청에 직접 문의해야 한다.**

- [ ] 관할 교육지원청에 "기존 학원에 원격교습 추가 가능한지" 문의

## 8. 순서 (서두르지 않는다)

| 단계 | 할 일 | 언제 |
|---|---|---|
| 0 | 학습 항목에 **학습 방법** 채우기 (9개) · 교육지원청 문의 | 지금도 할 수 있음 |
| 1 | **재원생 1~2명으로 2주 파일럿** — 지금 앱 기능(제출 + 등원 전 검사 + 리포트)만으로 | 대면 앱 만들 때와 같은 방법 |
| 2 | 파일럿에서 나온 불편을 아래 "쓰면서 나온 것" 에 적기 | 파일럿 중 |
| 3 | 앱 보강 — **검사함 · 수강 형태 · 학습 시간 · 미제출 재촉** | 파일럿 후 |
| 4 | 온라인 단어시험 응시 화면 | 그 다음 |
| 5 | 요금 정하고 신규 모집 | 마지막 |

**1단계를 건너뛰지 않는다.** 며칠 써보면 고칠 게 가장 정확하게 나온다는 걸
오늘 수업 화면에서 이미 확인했다.
