## 🔴 내가 결정해야 하는 것

### 노션 단원 데이터가 없다
- [ ] 노션 3교재DB 110권 전부 **전체페이지수·전체Unit수·커리큘럼 연결이 비어 있음** (확인 완료)
- [ ] 3공통진도DB는 **행이 0개**, 데일리리포트 `개별진도`도 전부 빈칸
- [ ] 즉 **단원은 새로 입력해야 한다.** 가져올 데이터가 없음
- [ ] 규칙적인 교재는 `⚡ 단원 한 번에 만들기` (Unit 1~20, 10초)
- [ ] 불규칙한 교재(내신·모의고사)만 엑셀

### 교재 안내 문자 발송 내역 (전체 기간) — 아직 못 함
- [ ] 노션에서 **교재 안내 문자를 보낸 기록이 있는 DB를 못 찾음**
- [ ] 하원숙제DB의 `발송완료`는 **숙제 문자**라 그건 이관됨
- [ ] 확인해야 할 것: 교재 안내 발송 기록이 어디 남아 있나?
	- Make 실행 로그?
	- 솔라피/바티 발송 내역?
	- 노션의 다른 DB나 페이지?
	- 아니면 기록을 따로 안 남겼나?
- [ ] 위치를 알려주면 `/import` 에 탭을 하나 더 붙일 수 있음
- [ ] **7월이 아니라 전체 기간**을 원함 → CSV로 내보낼 때 필터 없이 전체 내보내기

### 수강료 계산 규칙
- [x] 수업일이 기준보다 많은 달 → 정가를 넘지 않게 상한 처리함 (2026-07-26)
- [ ] 수업일이 기준보다 **적은** 달은 자동 감액됨. 이게 맞나?
	  (예: 8회 기준인데 휴강으로 7회 → 280,000원. 그냥 정가 받는 학원도 있음)
- [ ] 결석은 차감하지 않음 (보강으로 처리). 맞는지 확인
- [ ] 형제 할인은 학생별 금액으로 넣게 되어 있음. 규칙으로 만들 필요 있나?

### 노션 단어 점수 해석
- [ ] 노션 `-단어T` = 4, `/단어T` = 150 인 행이 있음
- [ ] 앱은 `맞은 개수 / 전체 개수` 로 읽어서 **4/150** 이 됨
- [ ] `-단어T` 가 **틀린 개수**라면 이관 전에 바꿔야 함 → **확인 필요**
- [ ] 확인 후 알려주면 `lib/importNotion.js` 한 줄 수정

### 발송 수단
- [ ] 솔라피 가입 · **발신번호 사전등록** (1~2일 소요)
- [ ] 문자로 시작 → 문구 굳으면 알림톡 템플릿 심사
- [ ] 앱 알림(무료)로 옮길 것: 숙제 안내
- [ ] 문자로 남길 것: 데일리리포트, 중요 공지
