## 조심할 것 (이번에 배운 것)

- **e2e 는 main 푸시라도 `supabase/**`·`scripts/e2e/**` 를 건드릴 때만
  자동으로 돈다.** 그 밖은 `gh workflow run e2e --ref <브랜치>` 로 직접.
  run 을 지켜볼 땐 **headSha 를 기대 커밋과 대조**한다 — 같은 브랜치의
  옛 run 을 보고 초록이라 믿은 사고가 이 밤에 실제로 있었다.
- **CI 는 Node 20** — supabase-js 를 스크립트에서 쓰면
  `realtime: { transport: class {} }` 없이는 생성자에서 죽는다.
- **PostgREST 벌크 insert 는 행마다 키가 같아야** 한다(PGRST102) —
  키 집합별로 나눠 보낸다 (골든 씨앗이 이 방식).
- 새 SQL 은 번호 충돌 주의: 0166·0167 은 특강(RLS·label)이 썼고
