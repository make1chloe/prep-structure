# Supabase 새 프로젝트로 옮기기

계정이 꼬였을 때, 지금 쓰는 계정으로 프로젝트를 새로 만들어 연결하는 방법.
현재 DB에는 테스트 데이터만 있으므로 잃을 것이 없다.

---

## 1. 새 프로젝트 만들기

1. https://supabase.com 로그인 (지금 들어가지는 계정 그대로)
2. **New project**
3. 입력
   - Name: `chloe-lms`
   - Database Password: 아무거나 (앱에서는 안 쓰지만 **어딘가 적어두기**)
   - Region: **Northeast Asia (Seoul)** ← 속도에 중요
4. **Create new project** → 1~2분 대기

## 2. 표 만들기 (한 번만)

1. 왼쪽 **SQL Editor**
2. 저장소의 **`supabase/SETUP_ALL.sql`** 파일 내용을 통째로 복사해 붙여넣기
3. **Run** → Success 확인

> 이 파일 하나에 지금까지의 모든 표·정책·기본값이 다 들어 있다.
> 여러 번 실행해도 안전하다.

## 3. 접속 정보 복사

**Project Settings → API** 에서 두 값을 복사한다.

| 항목 | 어디에 쓰나 |
|---|---|
| Project URL (`https://xxxx.supabase.co`) | `NEXT_PUBLIC_SUPABASE_URL` |
| anon public key | `NEXT_PUBLIC_SUPABASE_ANON_KEY` |

⚠️ URL은 **`.supabase.co` 까지만**. 뒤에 `/rest/v1/` 을 붙이면 로그인이 안 된다.

## 4. Vercel 환경변수 교체

1. Vercel → 프로젝트 → **Settings → Environment Variables**
2. 위 두 값을 **새 프로젝트 것으로 수정**
3. **Deployments → 맨 윗줄 → Redeploy** (Build Cache 체크 해제)

## 5. 로그인 계정 만들기

1. Supabase → **Authentication → Users → Add user**
   - 이메일·비밀번호 입력, **Auto Confirm User 체크**
2. **SQL Editor** 에서 원장으로 지정 (이메일만 바꿔서 실행)

```sql
update public.profiles
set role = 'principal', name = '클로이'
where id = (select id from auth.users where email = '내이메일@example.com');
```

3. 앱에서 그 계정으로 로그인
